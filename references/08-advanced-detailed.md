## 0. 三条「环境级」前提（不满足则什么都测不出来）

### 0.1 源码必须 GBK + **CRLF**；LF 会直接编译失败

用 `write` 类工具写出的 LF 源码，编译必然报内部错误（4/4 复现）：

```
实测：tmp\adv\p00.txt（LF，内容与 CRLF 版完全相同，63 字节）
BUILD_FAIL
--- compiler messages ---
-> 内部错误 -> Invalid procedure call or argument [:第0行]
ARTIFACT: <none>
```
改成 CRLF 后同一个文件（68 字节）立刻 `BUILD_OK` 并输出 `你好`。
→ **结论：`.txt` 源码必须 CRLF**（我后来统一用 `-replace "\n","\r\n"` 再写 GBK）。

### 0.2 编译器/运行期有「假死」：同一份产物可能第一次不出结果，重试即可

```
实测：tmp\adv\n1.txt（内容固定不变）
第 1 次 → [TIMEOUT 2s -> killed]
第 2 次 → [exit=0] 你好
第 3 次 → [exit=0] 你好
```
另有 `编译完毕.` 同时附带 `目标程序已经运行，请关闭程序` 的情况——那是**上一轮的进程没死**、
占着产物文件导致新产物写不进去。
→ 对策：每次编译前 `Get-Process <产物名> | Stop-Process -Force`，且失败自动重试。
本笔记所有"PASS"都是带重试的封装脚本 `tmp\adv\run.ps1` 得到的（PASS 的那次输出被抄录）。

### 0.3 【致命】文件里第一个 `程序`/`函数` 就是程序入口

辅助函数/子类方法如果写在入口之前，它会被当成入口执行 → 参数乱码、无输出、异常退出码。

```
实测：tmp\adv\t5.txt（辅助函数在前）
BUILD_OK → [exit=67108864]（无任何输出）
实测：tmp\adv\t6.txt（入口在前、辅助在后）
BUILD_OK → [exit=9] t6 r=25        ← 正确
```
这一条解释了本次实测中绝大多数「BUILD_OK 但无输出」的怪现象（例如机器指令函数写成第一个 `程序`：
`p07a` → `[exit=2000301232]` 无输出；把入口挪到最前面后 `adv-7` → `A 指令[] 机器加法(3,4)=7`）。
→ **模板永远是：`程序 初始启动` 第一个出现，其余 `程序` 全部写在它后面。**
（子类 `子类 名称{ ... 程序 方法 ... }` 里的方法**不算**入口，`adv-11` 子类写在入口前也能跑。）

## 1. 指针、内存、数组（文档第七节 1403–1628）

### 1.1 最小可用模板（示例 `examples\adv-1.txt`）

```极语言
程序类型=2
模块文件=CMD.inc
整数 m;
文本 内容[64]="0123456789ABCDEF";
程序 初始启动
m=申请内存(128);
m(13)=128;
写格式("A m(13)=%d\r\n",m(13));
写格式("B 内容(1)=%d\r\n",内容(1));
清零(m,16);
写格式("C 清零后 m(13)=%d\r\n",m(13));
填充内存(m,65,16);
写格式("D 填充后 m(0)=%d m(15)=%d\r\n",m(0),m(15));
内存复制(m,"ABCD",4);
写格式("E 复制后 m(0)=%d m(3)=%d\r\n",m(0),m(3));
写格式("F @m=%X @内容=%X\r\n",@m,@内容);
传址[m,66];
写格式("G 传址后 m(0)=%d\r\n",m(0));
写文字(内容);
写字符(10);
释放内存(m);
写文字("H 释放内存完成");
结束
```

真实输出（BUILD_OK，`ARTIFACT: ...\adv-1.com (2048 bytes)`，`[exit=0]`）：

```
A m(13)=128
B 内容(1)=49
C 清零后 m(13)=0
D 填充后 m(0)=65 m(15)=65
E 复制后 m(0)=65 m(3)=68
F @m=402000 @内容=402004
G 传址后 m(0)=66
0123456789ABCDEF
H 释放内存完成
```

逐条结论：

| 语法 | 实测结果 |
|---|---|
| `申请内存(n)` | 返回整数地址（`@m=402000`，即 .com 的 0x400000 基址段，说明是真实指针） |
| `整数 m; m(偏移)=值` / `值=m(偏移)` | 按**字节**读写，`m(13)=128` → `m(13)` 读出 128 |
| `文本 内容[64]="0123456789ABCDEF"; 内容(1)` | 得到 49 = `'1'` 的 ASCII，即文本缓冲区可当字节数组读 |
| `@变量` | 取地址；`@m=402000`、`@内容=402004` —— `整数 p=文本变量;` 与 `@` 等价 |
| `清零(m,16)` | 16 字节清零（原 m(13)=128 → 0） |
| `填充内存(m,65,16)` | memset，16 字节全 65 |
| `内存复制(m,"ABCD",4)` | memcpy，`m(0)=65('A')`、`m(3)=68('D')` |
| `传址[m,66]` | movads，直接往地址 m 写值 → `m(0)=66` |
| `释放内存(m)` | free，之后仍可继续执行后面的语句 |

### 1.2 `索引/检索` 与指针宽度后缀（示例 `examples\adv-2.txt`）

```极语言
整数 m,n,序号;
程序 初始启动
m=申请内存(32);
填充内存(m,0,32);
m(0)=65;m(1)=66;m(2)=67;m(3)=68;m(4)=69;
序号=检索(m,67,32);
写格式("A 检索(m,67,32)=%d\r\n",序号);
序号=检索(m,99,32);
写格式("B 检索(m,99,32)=%d\r\n",序号);
n=m(0)%;
写格式("C m(0)%%=%d\r\n",n);
n=m(0)&;
写格式("D m(0)&=%X\r\n",n);
释放内存(m);
写文字("E ok");
结束
```
真实输出（BUILD_OK，`[exit=0]`）：

```
A 检索(m,67,32)=2
B 检索(m,99,32)=-1
C m(0)%=16961
D m(0)&=44434241
E ok
```

- `检索(内存/数组, 目标值, 长度)`：返回**首次出现的字节下标**，找不到返回 **-1**（`检索(m,99,32)=-1`）。
- `m(0)%` = 读 2 字节：m(0)=0x41,m(1)=0x42 → **0x4241 = 16961**（小端）。
- `m(0)&` = 读 4 字节：41 42 43 44 → **0x44434241**。
- 文档里 `变量[n]` / `_[n]` / `#偏移` / `.偏移` 这几组"虚指针"写法**未验证**（本次只验证了 `变量(偏移)` 家族）。
- `传送(变量,表名,[字段名])`（配合检索把表字段搬进数组）**未验证**。
- `循环数组(条件){...}` **未验证**：`tmp\adv\w10.txt` 使用 `循环数组(n<m(64)){m(n)=n}` 连续 4 次 TIMEOUT、无输出；
  去掉该语句后同一份代码拆成 `adv-2`/`adv-1` 都正常，疑似 `循环数组` 在本版不可用（**存疑，未隔离**）。

## 2. 列举语法（文档 1435–1443）

`列举 变量{.成员=值; .成员2=值}` 可写可读。示例 **`examples\adv-13.txt`**（BUILD_OK，`[exit=17]`）：

```极语言
结构 人物类{整数 等级,职业,攻击,生命;}
人物类 人物;
整数 物攻,血量;
程序 初始启动
列举 人物{.等级=35;.职业=6;.攻击=7;.生命=99}
写格式("A 等级=%d 职业=%d 攻击=%d 生命=%d\r\n",人物.等级,人物.职业,人物.攻击,人物.生命);
列举 人物{物攻=.攻击;血量=.生命}
写格式("B 物攻=%d 血量=%d\r\n",物攻,血量);
人物.等级=1;
人物.职业=2;
写格式("C 等级=%d 职业=%d\r\n",人物.等级,人物.职业);
结束
```
真实输出（BUILD_OK，`[exit=17]`）：

```
A 等级=35 职业=6 攻击=7 生命=99
B 物攻=7 血量=99
C 等级=1 职业=2
```
结论：
- `.成员=值` 是**写**（等价 `人物.等级=35`）；
- `变量=.成员` 是**读**（把成员值复制到外部变量，文档示例 `物攻=.攻击;血量=.生命` 成立）；
- 列举与逐条 `变量.成员=值` 完全等效（A 行与 C 行对照）。

## 3. 结构体（文档第十节 1830–1943）

### 3.1 可用写法（示例 `examples\adv-3.txt`，BUILD_OK，`[exit=7]`）

```极语言
程序类型=2
模块文件=CMD.inc
结构 坐标类{整数 左,顶;}
结构 矩形类X{整数 左,顶,宽,高;}
坐标类 坐标;
坐标类 坐标组[3];
矩形类X 矩形2(宽=100,高=200);
矩形类X 矩形组[2]={{1,2,3,4},{5,6,7,8}};
程序 初始启动
坐标.左=10;坐标.顶=20;
写格式("A %d %d\r\n",坐标.左,坐标.顶);
坐标组(0).左=1;坐标组(2).顶=9;
写格式("B %d %d\r\n",坐标组(0).左,坐标组(2).顶);
写格式("C %d %d %d %d\r\n",矩形2.左,矩形2.顶,矩形2.宽,矩形2.高);
写格式("D %d %d\r\n",矩形组(1).左,矩形组(1).高);
结束
```
真实输出：

```
A 10 20
B 1 9
C 0 0 100 200
D 5 8
```

- 关键字用 **`结构`**（文档 `sec.clean.txt:699` 的 `typedef struct | 结构` 表项），用法就是 `结构 名称{类型 成员,成员2;...}`；
  文档另一处把同样的东西叫 `类型`（第 1834 行「极语言里自定义结构体就叫"类型"」）——**`类型` 未实测**。
- `名称 变量;` → `变量.成员=值` / 读 `变量.成员`。
- 结构体数组：`坐标类 坐标组[3];` → 下标用**小括号** `坐标组(0).左=1`（与数组一致，不是 `[0]`）。
- 括号初始化（仅指定部分成员，未指定=0）：`矩形类X 矩形2(宽=100,高=200);` → `C 0 0 100 200`。
- 数组大括号初始化（必须全部成员、按位置对应）：`矩形类X 矩形组[2]={{1,2,3,4},{5,6,7,8}};` → `D 5 8` ✔。

### 3.2 踩坑与失败实录

| 写法 | 结果（真实） |
|---|---|
| `矩形类X 矩形={10,20,800,600};`（**单个**结构变量用大括号） | BUILD_OK 但程序 `[exit=-1073741819]`（0xC0000005 访问违规），无任何输出（`tmp\adv\q5.txt`） |
| `长(坐标类)` 求类型长度 | `BUILD_FAIL`：`-> 符号 长 不存在.  [p04c.txt :第6行]` |
| `长度(坐标类)` | `BUILD_FAIL`：`-> 符号 长度 不存在.  [p04d.txt :第5行]` |
| `数据表 玩家表{...}` 里 `长(玩家表)` | `BUILD_FAIL`：`-> 符号 长 不存在.  [p05.txt :第12行]` |

→ **本版没有 `长()`/`长度()` 这两个求结构长度/表长度的符号**（文档 1962 行说 `长(表名)` 可用，与实际不符）。
求字节数只能自己数或用 `长度(变量)` 之类的库函数（未找到替代，**未验证**）。

### 3.3 结构体里的 `文本` 成员：必须 `定义 位数=64;`

文档 699 行给的 `结构 窗口类{整数 句柄,左边;文本 标题[64],内容[256]}` **不能照抄**：

| 变体 | 结果 |
|---|---|
| 无 `定义 位数` | BUILD_OK，运行 `[exit=-1073741795]`（0xC000001D 非法指令），无输出（`q2.txt`） |
| `定义 位数=32;` | BUILD_OK，运行连续 4 次 TIMEOUT、无输出（`r1.txt`） |
| **`定义 位数=64;`** | ✓ 正常（`r2.txt` → `r2 100 你好`；`s4.txt` → `s4 100 你好`） |

示例 `examples\adv-10.txt`（BUILD_OK，`[exit=10]`）：

```极语言
程序类型=2
模块文件=CMD.inc
定义 位数=64;
结构 窗口类{整数 句柄,左边;文本 标题[64],内容[256]}
窗口类 窗一;
程序 初始启动
窗一.句柄=100;窗一.左边=7;
内存复制(窗一.标题,"你好",5);
写格式("A 句柄=%d 左边=%d\r\n",窗一.句柄,窗一.左边);
写文字(窗一.标题);
写字符(10);
结束
```
真实输出：
```
A 句柄=100 左边=7
你好
```
（`内存复制` 灌字符串是最稳的写法；直接 `窗一.标题="你好"` 在 `位数=64` 下也能出 `r2 100 你好`，
但按技能库的经验这种"向文本变量赋值"极易死循环，**推荐内存复制**。）

## 4. 数据表（文档第十一节 1944–2082）

### 4.1 可用写法（示例 `examples\adv-4.txt`，BUILD_OK，`[exit=24]`）

```极语言
程序类型=2
模块文件=CMD.inc
数据表 玩家表{整数 等级,职业;}
程序 初始启动
重置 玩家表(10);
玩家表(0).等级=35;
玩家表(0).职业=6;
玩家表(3).等级=99;
写格式("A %d %d %d\r\n",玩家表(0).等级,玩家表(0).职业,玩家表(3).等级);
写格式("B len=%d rows=%d cols=%d\r\n",玩家表.len,玩家表.rows,玩家表.cols);
结束
```
真实输出：

```
A 35 6 99
B len=10 rows=0 cols=2
```

- `数据表 名称{类型 字段,...}` 定义在**全局**（入口之前）。
- 使用前必须 `重置 表名(行数);`（申请内存并清零）。
- 索引读写：`表名(行号).字段名`，行号从 **0** 开始。
- 内置成员：`.len`=已申请行数(10)、`.rows`=已读取行数（不连数据库时是 0）、`.cols`=列数(2)。
  文档还写了 `.指针`（缓冲区指针），**未验证**（含 `文本` 字段的表会崩，见下）。
- **数据表字段只验证了 `整数`**。文档示例 `数据表 账号表{文本 密码[16],密保[16],邮箱[16];整数 性别}`
  在本版**不可用**：
  - `tmp\adv\q10.txt`：BUILD_OK → `[exit=-1073741819]`（0xC0000005），无输出；
  - `tmp\adv\s8.txt`、`r9.txt`（加 `位数=64`）：BUILD_OK → 连续 TIMEOUT、无输出。
  → 结论：**数据表里放 `文本[n]` 字段会崩/卡死**，需要文本时另建数组或 `申请内存` 自己管（**替代方案未验证**）。
- 与数据库的关系（文档 2030–2081）：`数据.连接(连接串)` → `数据.执行(sql)` → `数据.读表("表名")` → `读取表(库表,账号表[,长度])`，
  用 `读取表` 时指定长度会自动销毁旧内存再按实际行数申请。**本次未验证（无数据库环境）**。

## 5. 子类与对象（文档第十二节 2083–2252）

### 5.1 可用写法（示例 `examples\adv-11.txt`，BUILD_OK，`[exit=10]`）

```极语言
程序类型=2
模块文件=CMD.inc
定义 位数=64;
子类 角色类{
整数 攻击,防御;
文本 名字[16];
程序 说话
写文字("说话() 被调用");
写字符(10);
结束
}
程序 初始启动
角色类 玩家=新建 角色类(攻击=1,防御=2);
写格式("A 攻击=%d 防御=%d\r\n",玩家.攻击,玩家.防御);
玩家.攻击=30;
内存复制(玩家.名字,"阿丙",5);
写文字(玩家.名字);
写字符(10);
玩家.说话;
写格式("B 攻击=%d\r\n",玩家.攻击);
销毁 玩家;
写文字("C 已销毁");
结束
```
真实输出（**注意只出来了方法那一行**）：

```
[exit=10]
说话() 被调用
```

- `子类 名称{ 成员变量; 程序 方法 ... 结束 }` —— **本版用 `程序`，`小程序` 不是关键字**（官方 `code\*.sec` 里全是旧的 `小程序/程序段`，照抄会编译失败）。
- `新建`：`角色类 玩家=新建 角色类(攻击=1,防御=2);` ✔（带初始值，`w5.txt` → `w5 攻击=1 防御=2`）；
  `整数 玩家=新建 角色类;`（用整数当句柄）也可 ✔（`u4.txt` → `u4 攻击=30`）。
- 成员读写 `玩家.攻击=30` / `玩家.攻击` ✔；**成员是 `文本` 时用 `内存复制` 灌** ✔（`w7.txt` → `阿丙` / `w7 攻击=9`）。
- 无参无返回值方法调用 `玩家.说话;` ✔（`u1.txt` → `u1 说话被调用`）。
- `销毁 玩家;` ✔（能编译并执行到后面）。
- 坑：**同一文件里混用 `写格式` + 文本成员 + 方法调用时，入口里的前几条 `写格式` 输出会丢失**（只看到方法自己的输出）。
  `w5`/`w7` 单独测时 `写格式` 输出正常，说明不是子类本身的问题，**原因未查明（存疑）**。

### 5.2 失败实录（**带参数/带返回值的方法没跑通过**）

| 写法 | 真实结果 |
|---|---|
| `程序 计算(参数) 返回(攻击+参数) 结束`，调用 `写格式("...%d",玩家.计算(5))` | BUILD_OK → `[exit=-1978963627]` 无输出（`q9.txt`）；`s5/s6/s7/w3` 同样，4 种顺序/位数组合全军覆没 |
| 同上但先赋值：`整数 r=玩家.计算(5); 写格式("...",r)` | BUILD_OK → `[exit=-1978484395]` 无输出（`w2.txt`） |
| 带参无返回：`程序 设置(参数) 攻击=参数 结束` + `玩家.设置(77)` | BUILD_OK → 连续 TIMEOUT 无输出（`w1.txt`） |
| 无参有返回：`程序 取数 返回(7) 结束` + `玩家.取数` | BUILD_OK → `[exit=7]` 无输出（`u3.txt`，返回值 7 变成了进程退出码） |
| 子类数组：`角色类 玩家组[3]; 玩家组(0)=新建 角色类;` | BUILD_OK → 连续 TIMEOUT 无输出（`w6.txt`，文档 2219–2223 行的写法） |
| `子类` 只含方法、不 `新建`、直接 `角色类.取数`（文档 2179「子类如果不包含变量,是不需要新建」） | BUILD_OK → `[exit=7]` 无输出（`u5.txt`） |

→ **实用结论：本版子类只把「成员变量 + 无参无返回值方法」跑通了；带参/带返回值的方法不要用**，
必须传数据时用成员变量或 `@`/指针去递（文档 2126–2132 的 `@` 代表子类本身，**未验证**）。

### 5.3 对象 / COM（文档 2227–2251）

`对象 名称=对象名;` → `创建对象 名称;` → `名称.方法(...)` → `名称.释放;`（**没有** `新建`/`销毁`）。
含 CLSID/IID 的完整写法、简写（`$0B01`、`$42`）、`任务栏类` 等内置对象、`.类`/`.标识` 成员：
**全部未验证**（本机未做 COM 实验，且控制台模式下大概率还依赖 ole32/shell32 模块）。

## 6. 常量与定义（文档第十三节 2253–2343）

### 6.1 `常量` + 中括号表达式（示例 `examples\adv-5.txt`，BUILD_OK，`[exit=22]`）

```极语言
程序类型=2
模块文件=CMD.inc
常量 确定取消=1,中止重试=2,问号图标=0x20;
常量 样式=[确定取消+问号图标];
常量 混合=[6+[35-12]*150-[60/12]];
常量 位或=[确定取消|问号图标];
常量 行数=4;
结构 记录{整数 甲,乙;}
记录 表2[行数];
程序 初始启动
写格式("A %d %d %d %d\r\n",确定取消,样式,混合,位或);
表2(3).甲=7;
写格式("B 表2(3).甲=%d 行数=%d\r\n",表2(3).甲,行数);
结束
```
真实输出：

```
A 1 33 4345 33
B 表2(3).甲=7 行数=4
```

- `常量 名称=值;` 支持逗号连写：`常量 确定取消=1,中止重试=2,问号图标=0x20;`（十六进制 `0x`/`$` 都行）。
- `[ ]` = **编译期求值**：`[确定取消+问号图标]` → 33（0x21）；`[确定取消|问号图标]` → 33（或运算/加法等价）。
- `[6+[35-12]*150-[60/12]]` → **4345**。按"先乘除后加减"应是 3451，因此证实文档所说
  **中括号内按顺序从左到右**：`((6+(35-12))*150)-(60/12)=29*150-5=4345`。
  需要优先级就再套一层中括号。
- **编译期常量可以直接当数组长度/结构体数组长度**：`常量 行数=4; 记录 表2[行数];` → `B ... 行数=4` ✔。
- `常量` 后面不加中括号时是普通数值定义，不加中括号的表达式会在运行期算（未单独验证）。

### 6.2 `定义` 的雷区：`定义 名称=数值;` 会编译失败

```
实测：examples\adv-12.txt（= tmp\adv\y8.txt）
程序类型=2
模块文件=CMD.inc
定义 千=1000;
程序 初始启动
写格式("千=%d\r\n",千);
结束
→ BUILD_FAIL
--- compiler messages ---
-> 内部错误 -> Subscript out of range [y8.txt :第3行]
```
同一现象在 `tmp\adv\y3.txt`、`tmp\adv\p09.txt` 里复现（都是加了 `定义 千=1000;` 之后，
错误位置被报在**下一行**，即 `程序 初始启动` 那行）。
→ **`定义` 在本版只用于"配置/指令集/端口"等特殊形式**（`定义 位数=32;`、`定义 后缀=dll;`、`定义 基址=`、
`定义 端口0=0x80;`、`定义 存入="50:0";` —— 见下节，最后一种实测可用）。
**普通数值常量请一律用 `常量 名称=值;`。**

## 7. 跳到 / 跳转 / 标记（文档第九节 1683–1829）

示例 `examples\adv-6.txt`（BUILD_OK，`[exit=10]`）：

```极语言
程序类型=2
模块文件=CMD.inc
整数 和,甲,乙,丙;
程序 初始启动
和=0;甲=1;
标记 累加;
和=和+甲;
甲++;
如果(甲<=100){跳到 累加}
写格式("A 1..100 和=%d\r\n",和);
甲=5;乙=3;丙=甲-乙;
跳转> 大方;
写文字("B 没跳(不大于)");
跳到 收;
标记 大方;
写文字("B 跳了(大于)");
标记 收;
写字符(10);
结束
```
真实输出：

```
A 1..100 和=5050
B 跳了(大于)
```

- `标记 名称;` 定义标号，`跳到 名称` 无条件跳转；用 `如果(条件){跳到 标记}` 实现 1..100 累加 → **5050 正确**。
- `跳转> 标记` 是条件跳转，它**不自己比较**，用的是**上一条运算指令留下的标志位**：
  `丙=甲-乙`（5-3=2，SF=0/ZF=0）→ 有符号">"成立 → 跳到 `大方`，输出"跳了(大于)" ✔。
  （所以必须先做减法/比较，再写 `跳转>`；文档 1743–1745 的例子也是这个套路。）
- 未验证：`跳转 < 标记`、`跳转 小于 标记`、`跳转 #0 标记`～`跳转 #F 标记` 全部条件码、以及文档
  1755–1757 行的 `标记1:` 纯冒号写法。

## 8. 置入指令与机器指令（文档第八节 1629–1682）

示例 `examples\adv-7.txt`（**修正入口顺序后** BUILD_OK，`[exit=31]`）：

```极语言
程序类型=2
模块文件=CMD.inc
定义 存入="50:0";
定义 弹一="58:0";
程序 初始启动
整数 r=机器加法(3,4);
写格式("A 指令[] 机器加法(3,4)=%d\r\n",r);
整数 s=机器和(3,4);
写格式("B 定义存入/弹一 机器和(3,4)=%d\r\n",s);
结束
程序 机器加法(数一,数二)
指令[8B45088B4D0C8D0401];
结束
程序 机器和(数一,数二)
指令[8B4508];
存入(0);
指令[8B4D0C];
弹一(0);
指令[01C8];
结束
程序 置入演示()
置入[字节 15,20,40];
置入[整数 66,$204068AA];
置入[整形 $2040,88];
结束
```
真实输出：

```
A 指令[] 机器加法(3,4)=7
B 定义存入/弹一 机器和(3,4)=7
```

- **`指令[...]` 能直接写 x86 机器码**，字节就是 `8B4508`=`mov eax,[ebp+8]`、`8B4D0C`=`mov ecx,[ebp+0Ch]`、
  `8D0401`=`lea eax,[ecx+eax]`。3+4=7 ✔。
  → 参数从 `[ebp+8]` 起，说明**编译器已经生成标准栈帧**，函数体只需要写"干活"的指令；
  **不要自己写 `C3`(ret)**，收尾由编译器生成。
- `定义 存入="50:0";` / `定义 弹一="58:0";`：冒号后的 `0` 表示"操作码+寄存器号"，`存入(0)`=`push eax`(0x50)、
  `弹一(0)`=`pop eax`(0x58)。用它把 `eax` 压栈保存、`ecx` 装载第二参数后再弹回 `eax`，
  `01C8`=`add eax,ecx` → 3+4=7 ✔（**自定义机器指令可用**）。
- `置入[字节 15,20,40]; 置入[整数 66,$204068AA]; 置入[整形 $2040,88];` 编译通过（数据放在一个
  **永不调用**的函数里，避免跑飞）。

### 8.1 置入的报错实录

| 写法 | 真实编译器原话 |
|---|---|
| `置入[小数 3.14];` | `-> 置入错误:小数 [adv-7.txt :第24行]` |
| 同时含 `置入[文本 "你好"];置入[文本 50];置入[全局 窗体];置入[@ 机器加法];` | `-> 置入错误: [adv-7.txt :第27行]`（**信息为空**，未逐条隔离出到底哪一条非法） |

→ 文档 1663–1681 的置入功能表里，**实测可用：`字节`/`整数`/`整形`；实测报错：`小数`；
   `文本`/`全局`/`局部`/`调用`/`函数`/`@` 未逐条验证**。
→ 另一个必须记住的坑：文档 CRC 例子（`code\crc32.sec` 的 `校验开启/校验数据`、HIF.sec 的 `加解密`）
  把 `指令[...]` 函数写在很前面——**在本版必须把 `程序 初始启动` 放在文件最前面**，
  否则那个机器码函数会变成入口直接跑飞（`tmp\adv\p07a.txt` → `[exit=2000301232]` 无输出）。

## 9. DLL：导入、支持库、动态调用、导出（文档 2439–2535）

### 9.1 【最小可运行模板】控制台调用 Windows API（示例 `examples\adv-8.txt`）

```极语言
程序类型=2
模块文件=CMD.inc
引入 "lib\kernel32.lib";
导入 开机毫秒 支持库 "KERNEL32.DLL",0;
导入 模块名称 支持库 "KERNEL32.DLL",3;
文本 路径[260];
程序 初始启动
写文字("DLL-BEGIN");
写字符(10);
整数 计数=开机毫秒;
写格式("A GetTickCount=%d\r\n",计数);
整数 长=模块名称(0,路径,260);
写格式("B GetModuleFileNameA=%d\r\n",长);
写文字(路径);
写字符(10);
写文字("DLL-END");
结束
```
真实运行输出（BUILD_OK，`ARTIFACT: ...\adv-8.com (2048 bytes)`，`[exit=0]`）：

```

A GetTickCount=14311515
B GetModuleFileNameA=38
D:\SEC\deepseek-sec\examples\adv-8.com

DLL-END
```

要点：
- `引入 "lib\kernel32.lib";` —— 引用导入库（`inc\cmd.inc` 本身就是一行
  `引入 "lib\kernel32.lib","lib\msvcrt.lib";`，`inc\dll.inc` 引入 user32/kernel32/shell32/ws2_32/msvcrt）。
  `lib\` 是相对 **D:\SEC\inc\lib** 解析的（真实的 .lib 都在 `D:\SEC\inc\lib\`）。
- `导入 名称 支持库 "DLL名",参数个数;` —— **最后一个数字必须等于参数个数**：
  `开机毫秒`(GetTickCount) 是 0 个参数；`模块名称`(GetModuleFileNameA) 是 3 个。
  名字用**中文函数表里的中文名**（`lib.clean.txt`/`msapi.clean.txt`）即可，编译器知道它对应哪个 API。
- 无参 API 直接写名字取值：`整数 计数=开机毫秒;`（**不带括号**）。
- 有参数 API 正常括号调用：`模块名称(0,路径,260)` → 返回写入的字符数 38，并把路径写进 `文本 路径[260]`，
  随后 `写文字(路径)` 打印出 `D:\SEC\deepseek-sec\examples\adv-8.com` ✔（缓冲区地址自动传递）。
- 这是**加载时动态链接**（链接进 PE 导入表），不需要 `加载库`。

## 11. 复现方式（本次所有实测的跑法）

```powershell
# 1) 把 UTF-8 源转成 GBK + CRLF
$gbk=[Text.Encoding]::GetEncoding('GB18030')
$src=@'
程序类型=2
模块文件=CMD.inc
程序 初始启动
写文字("hi");
结束
'@
[IO.File]::WriteAllText('D:\SEC\deepseek-sec\examples\adv-1.txt',$src,$gbk)

# 2) 编译 + 运行（失败/TIMEOUT 自动重试，并先杀掉上一次残留的进程）
& 'D:\SEC\deepseek-sec\tmp\adv\run.ps1' -Src 'D:\SEC\deepseek-sec\examples\adv-1.txt' -RunSeconds 4
```

- 示例源文件：`D:\SEC\deepseek-sec\examples\adv-1.txt` … `adv-11.txt`（全部 GBK+CRLF，全部实测 BUILD_OK），
  以及反例 `adv-12.txt`（`定义 名称=数值;` 的编译失败样本，BUILD_FAIL 是预期结果）。
- 探针与二分定位用的一次性源：`D:\SEC\deepseek-sec\tmp\adv\*.txt`（p/q/r/s/t/u/w/y/z 系列），
  辅助脚本 `tmp\adv\mk.ps1`（UTF-8→GBK/CRLF）与 `tmp\adv\run.ps1`（带重试与进程清理的编译运行封装）。
