# 04 · 指针 / 结构体 / 数据表 / 子类 / DLL（实测笔记）

对应官方文档 `docs/sec.clean.txt` 第七~十三节 + DLL 章节。每条标注验证状态（本机实测 / 文档）。

## 1. 指针与内存（实测）

极语言没有专门的指针类型：**整数变量本身就是"万能指针"**（文档第二节：`整数变量也是万能的指针`）。

```ji
整数 s="sdkfskd";      // 字面量本身就是地址，可赋给整数（实测 r3：写文字(p) → abc）
s(0)=\b;               // 指针 + 偏移，读写 1 字节（文档第六节）
整数 p=文本变量;        // 取文本缓冲区首地址（文档，实测 内容.指针 成员不可用）
整数 m=申请内存(128);   // malloc
m(13)=128;             // 第 14 字节写入
a=m(10);               // 第 11 字节读出
释放内存(m);
```

按长度访问（符号写在变量或 `变量(偏移)` 之后）：

| 写法 | 含义 | 实测 |
|---|---|---|
| `变量(偏移)` | 1 字节 | ✅ `内容(2)` → 字符 '2' 的 ASCII 50；`内存(i)=10` 判断换行；`行(0)=65` 造字符串 |
| `变量(偏移)%` | 2 字节 | 文档 |
| `变量(偏移)&` | 4 字节 | 文档；`数据&`＝取 4 字节内存值 |
| `变量(偏移)!` | 4 字节浮点 | 文档 |
| `.偏移` `.%偏移` `.&偏移` `.!偏移` | 相对当前列举基址 | 文档（旧式写法 `#偏移` / `#%偏移`） |

实测样例（造字符串，`app-mandelbrot` / `app-baseconv` 都用这个办法）：

```ji
文本 行[96];
行(0)=0;            // 清空
行(0)=65;行(1)=66;行(2)=0;
写文字(行);          // → AB
```

内存/字符串函数（`CMD.inc`，实测/文档）：`申请内存 申零内存 保留内存 释放内存 内存复制 内存传送 填充内存 查找字节 内存比较`（`lib.clean.txt` 704–724 行）、`查找文字 文字复制 前字复制 查字符 文字长度`（819–845 行）。

## 2. 结构体（实测）

```ji
结构 玩家{整数 生命,攻击; 文本 名字[32]}
玩家 甲;                       // 单个结构变量：全局或函数内都可以（实测 st2/st3）
程序 初始启动
甲.生命=100;
内存复制(甲.名字,"赵子龙",7);
写格式("生命=%d 名字=",甲.生命);
写文字(甲.名字);                // → 生命=100 名字=赵子龙（实测 sw1/sw2）
结束
```

要点：

- 成员访问用 `.`；成员类型支持整数/字节/文本等。
- ★ **含 `文本` 成员的结构体在默认 32 位下会崩溃/卡死，加 `定义 位数=64;` 即恢复正常**（实测：`结构 玩家{整数 生命;文本 名字[32]}` → w64b 输出 `生命=100 名字=赵子龙`；无位数时崩溃 0xC000001D）。
- 单个结构变量**大括号整块初始化会崩溃**（`变量={10,20,800,600}` → 0xC0000005）；数组形式 `组[2]={{...},{...}}` 可用（adv-3/adv-5 实测）。
- ★ **结构体数组不可用**：`玩家 队伍(3);` 或 `玩家 队伍[3];` 编译通过但**运行即卡死/无输出**（实测 sw3/sw4/sx1/sx2，控制台窗口空白）。官方文档写的是 `窗口类 窗一[10]; 窗一(0).标题="你好"`，但本版实测不行。
  → 需要"记录数组"时用 `数据表`（见下）或并行数组（`整数 生命(100)` + `整数 攻击(100)`）。
- 结构体长度/偏移可用文档第九节的 `列举` 语法整块赋值：`列举 人物{.等级=35;.职业=6; 物攻=.攻击}`（实测 adv-13 → `等级=35 职业=6 攻击=7 生命=99` ✓）。

## 3. 数据表（实测 ✓ 推荐用于"记录数组"）

```ji
数据表 人物{整数 生命; 字节 等级,职业}
程序 初始启动
重置 人物(50);        // 分配 50 条记录并清零
人物(0).生命=500;
人物(1).等级=9;
写格式("生命=%d 等级=%d",人物(0).生命,人物(1).等级);   // → 生命=500 等级=9（实测 dt1 ✓）
结束
```

- `重置 表名(数量)` 分配；索引写 `表名(序号).字段`；字段类型可混合（整数/字节/…）。
- ★ **数据表只能放整数类字段**：塞 `文本` 字段会崩溃(0xC0000005)或卡死（文档里的"账号表"例子照抄会死）。
- 成员 `.len`（分配条数）`.rows` `.cols` 可用（实测 adv-4：`len=10 rows=0 cols=2`）。
- 官方文档第十一节还提到数据库相关（`读取表` 等），未实测。

## 4. 子类与对象（实测：成员可用，方法有前提）

```ji
子类 角色{整数 生命,攻击;}
程序 初始启动
整数 甲=新建 角色;      // 实体是整数指针变量，数据自动清零
甲.生命=100;
写格式("生命=%d",甲.生命);   // → 生命=100（实测 cx1 ✓）
销毁 甲;                     // 只支持销毁
结束
```

- `新建` 创建实例、`销毁` 释放；`子类` 成员就是普通变量，`.` 访问（实测）。
- ★ **子类方法**：本版只跑通「**成员 + 无参无返回值方法**」，且需要 `定义 位数=64;`。
  - 实测 w64c（位数=64，`程序 说话` 无参无返回，`甲.说话;` 调用）→ 输出 `说话被调用` ✓
  - 带参数的方法、带返回值的方法：**7 种变体全部失败**（32 位与 64 位都 TIMEOUT/异常退出码，实测 cx2/cx2_64）。
  - 文档说"子类代码需要单独一个模块文件来书写"，纯文本单文件下需要按上面两条限制使用。
- 子类内部访问自身用 `@`（文档 2126 行）；把子类当参数要写类型名：`程序 计算(角色类 人物)`（文档，未实测）。
- 子类定义**不算入口**：子类写在入口之前也能正常工作（adv 领域实测）。
- 子类数组未跑通（TIMEOUT）。

## 5. 常量与定义（文档）

```ji
常量 只读打开=0;            // 编译期常量，可作数组长度/结构长度
定义 位数=32;               // 工程配置（必须紧跟 程序类型/模块文件 之后）
定义 后缀=exe;              // 改产物扩展名（实测 ✓）
定义 名称=值;               // 文档：定义宏/指令/端口等
```

## 6. DLL 与 Windows API（实测 ✓ 两种写法都可用）

```ji
// 写法一：中文别名
导入 屏幕宽 别名 GetSystemMetrics 支持库 "USER32.DLL",1;
// 写法二：直接用原名
导入 GetSystemMetrics 支持库 "USER32.DLL",1;

程序 初始启动
整数 w=屏幕宽(0);
写格式("screen=%d",w);      // → screen=1920（实测 d1/d2 ✓）
结束
```

- 语法（文档 1094/1148 行）：`导入 <名称> [别名 <导出名>] 支持库 "<DLL>",<参数个数>;`；放在函数之外（配置区之后、代码之前）。**参数个数必须写准**；无参 API 调用时直接写名字、不带括号。
- 实测模板（`examples/10-adv-8.txt`，BUILD_OK）：
  ```ji
  引入 "lib\kernel32.lib";
  导入 取滴答 支持库 "KERNEL32.DLL",0;
  导入 取模块名 别名 GetModuleFileNameA 支持库 "KERNEL32.DLL",3;
  程序 初始启动
  写格式("GetTickCount=%d\r\n",取滴答);
  文本 路径[260];
  整数 长=取模块名(0,路径,260);
  写格式("GetModuleFileNameA=%d\r\n",长);
  写文字(路径);写字符(13);写字符(10);
  结束
  ```
- 弹模态消息框也验证通过：`导入 信息框A 别名 MessageBoxA 支持库 "USER32.DLL",4;`（`examples/10-adv-9.txt`，截图 `examples/adv-9-messagebox.png`）。注意模态框期间 stdio 不刷新，自动化跑它只会看到 TIMEOUT 且无输出——要看结果只能截图。
- ⚠ **动态调用不可用**：`加载库` / `函数地址` / `调用 变量(参数)` 4/4 TIMEOUT 零输出（未跑通）→ 一律走 `引入 + 导入`。
- 导出写 DLL：`程序类型=1`（扩展 DLL）+ `导出 计算(参数) 返回(参数+100) 结束`，编译出 `.dll`（文档 2439–2463 行，未实测）。
- 栈约定提醒（文档 415–417 行）：API 用 stdcall，C 运行库是 cdecl；循环里频繁直接调 C 运行库可能栈溢出，建议把这类调用**封装进一个 `程序` 里**（极语言会自动记录/还原堆栈）。
- 现成 API 中文名大全：`docs/lib.clean.txt`（C 运行库 + 常用 Win32 封装）、`docs/msapi.clean.txt`（Windows API 全表，中文名→英文名→参数说明）。

## 7. 机器指令 / 跳转标记（实测部分通过）

- ✅ **`指令[机器码]` 可用**：`程序 机器加法(数一,数二) 指令[8B45088B4D0C8D0401]; 结束` → `机器加法(3,4)=7`（实测 adv-7；注意辅助例程必须写在入口之后，否则它会变成入口）。
- ✅ **自定义指令**：`定义 存入="50:0"; 定义 弹一="58:0";` 再 `存入(0); … 弹一(0);` → `机器和(3,4)=7`。
- ⚠ `置入[字节/整数/整形 …]` 编译通过；`置入[小数 3.14]` → `置入错误:小数`。
- ✅ `标记 位置;` + `跳到 位置;` 可用（adv-6：`1..100 和=5050`）。
- ⚠ **`跳转>标记` 不可靠**（依赖上一条比较的标志位，时跳时不跳，实测 o6/adv-6 第一版）→ 用无条件 `跳到`。
- 寄存器中文名 `低一=al 存一=ax/eax/rax 存五=sp/esp/rsp` 等（文档第八节 1629+、1185–1219）。
- 扩展编译/宏指令的更多语法（`定义 控制="0F:5"; 远跳(显字符,8)` 等）见文档，未实测。
- 加密/哈希等示例见官方 `code\crc32.sec`。
