## 0. 编译环境与必须遵守的两个硬约束（实测）

```
powershell -File D:\SEC\deepseek-sec\tools\sec.ps1 -Src D:\SEC\deepseek-sec\examples\bas-1.txt -Run
```

| 约束 | 违反后的现象 | 证据 |
|---|---|---|
| 源码必须 **GBK 编码** | `未定义的名称:绋嬪簭绫诲瀷` 之类乱码 | 见技能/主 agent 笔记 |
| 源码必须 **CRLF 换行** | `-> 内部错误 -> Invalid procedure call or argument [:第0行]`（配置行都没解析就报错） | 实测：同一份内容 LF 版 `w2.txt`/`_probe1.txt` 连续 8 次 BUILD_FAIL；改成 CRLF 的 `w1.txt` 立刻 BUILD_OK 并输出 `A` |

> 写源码的最简流水线（UTF-8 写好 → 转 GBK+CRLF → 编译运行）：
> ```powershell
> $gbk=[Text.Encoding]::GetEncoding('GB18030')
> $t=[IO.File]::ReadAllText($src_u8,[Text.Encoding]::UTF8)
> $t=$t.Replace("`r`n","`n").Replace("`r","`n").Replace("`n","`r`n")
> [IO.File]::WriteAllText($out,$t,$gbk)
> ```
> 我用的可复用脚本：`D:\SEC\deepseek-sec\test\bas-build.ps1 -U8 <utf8源> -Out <gbk目标> -Run`。

**另外两点环境事实（实测）**
- 编译器偶发「假死」：同一份 BUILD_OK 的程序，第一次运行会 `[TIMEOUT]`，重跑一次就正常。`sec.ps1` 自带一次重试；并行调用 `sec.ps1` 会互相干扰（脚本会 kill 所有 `Sc.exe`），所以**要串行编译**，失败就重试。
- 报错行号偏移：**配置行不计入行号**（实测 bas-7 报 `第35行` = 源码第 37 行；bas-8 报 `第23行` = 源码第 25 行）。
- `结束` 的退出码 = **最后一条语句的返回值**（`写格式` 返回打印字符数）。实测 bas-1 `exit=0`、bas-3 `exit=0`、bas-4 `exit=0`、bas-6 `exit=0`；而 probe `q6.txt` 最后一条 `写格式("a=1 b=2 c=3\r\n",…)` 打印 13 字符 → `exit=13`。**不要用退出码判断成败。**

## 1. 程序结构与入口（bas-1.txt）

### 1.1 入口规则（本版最容易踩的坑）
> **源码里第一个出现的 `程序`/`函数` 定义就是程序入口**，它叫什么名字无所谓；辅助例程必须写在入口**之后**。

证据：
- `v1.txt`（`程序 甲` 写在 `程序 初始启动` 前面）→ 输出 `JIA-first`，`初始启动` 根本没跑。
- `v2.txt`（`初始启动` 在前）→ 输出 `MAIN-first`。
- `v3.txt`（`函数 乙` 在前）→ 输出 `YI-first`，且进程退出码 = 乙的返回值。
- `s5.txt`（`内层`/`外层`/`初始启动` 依次定义）→ 只输出 `inner`（跑了第一个例程 `内层`）。
- `p7.txt`（带参例程写在最前）→ `显示(42)` 里 `值` 是栈地址 `3870720`。
- `bas-1.txt`（入口在前、辅助在后）→ 全部输出正确（见下）。

### 1.2 最小可复制模板

```ji
程序类型=2          // 2=命令控制台；0=初级 Windows/GUI(默认)；1=扩展DLL；3=函数类库
模块文件=CMD.inc    // 控制台必须；提供 写文字/写格式/读字符/格式化/内存复制…
定义 位数=32;       // 可选，配置行必须紧跟在上面两行之后（实测 o8.txt BUILD_OK）
定义 后缀=com;      // 可选，改产物扩展名

整数 全局数=100;              // 全局变量：写在第一个 程序/函数 之前
文本 全局文本[32]="全局文本"; // 全局声明带初始值：实测正常

程序 初始启动                  // ★ 入口必须最先出现
	局部 整数 局部数=7;        // 局部变量，可加“局部”前缀
	写文字("你好");
	写格式("全局数=%d\r\n", 全局数);
结束

程序 加法(数一=10,数二=5)      // 辅助例程放后面
	返回(数一 + 数二)
结束

函数 乘法(数一,数二)           // “函数”+大括号体也可用（见下）
{
	返回(数一 * 数二)
}
```

### 1.3 `程序` / `函数` / `结束` / `{}`
- `程序 名称(参数,…)` 与 `函数 名称(参数,…)` **都可用**；函数体用 `结束` 收尾或用 `{ … }` 代替 `结束` 都行。
  实测 bas-1：`程序 加法(3,4)=7`、`函数 乘法(6,7)=42`（大括号体）都正确。
  （主 agent 另测到：某些上下文里用 `函数` 定义辅助例程会报「初始启动 语法有误/内部错误」→ **保守起见辅助例程用 `程序`**。）
- `返回(表达式)` 返回整数；文档说浮点结果写 `返回(:表达式)`——**实测不可靠**：`函数 半(值) 返回(:值/2)` 得到 `0.000`（d6.txt）。要返回小数请改用「双精」目标变量或输出参数。
- **形参默认值不生效（重要）**：`程序 加法(数一=10,数二=5)`，调 `加法()` 得垃圾值（bas-1 两次运行分别是 `2453504` / `2236416`，d1 实测 `2428933`——**每次运行都不一样，是未初始化栈内存**），调 `加法(5)` 得 `10`（第二个形参也是运气值）。→ **调用时一律写全实参**。
- 无参例程调用写 `名称;`；实测给 0 参例程加括号 (`writes();`) 会报 `writes 参数数量不符,应该有0个参数`。

### 1.4 变量作用域
- 在函数/子类**之外**申请 = 全局变量（静态数据空间）；**函数内**申请的、包括形参 = 局部变量（栈内存），退出函数自动释放。
- `局部 整数 x=7;` 显式写法可用（实测 `q5.txt` 输出 `loc-ok`；bas-1/bas-2 都在用）。
- 任何变量作参数传递都是 4 字节；`文本`/`浮点`/自定义类型传的是地址。
- 命名注意：全局变量叫 `全局计数` 时编译器会打印 `已存在函数名:全局计数` 警告（能编过，但改叫 `全局数` 就没警告——实测 d2.txt vs d3.txt）。**避免用 `全局计数` 当标识符**。

### 1.5 语句分隔与注释（实测）
- 分隔符：**换行、分号、空格、制表符、逗号**都能断开词元；`整数 a=1; 整数 b=2; 整数 c=3` 与逐行写等价（bas-1 输出 `a=1 b=2 c=3`）。
- 一条语句结束用换行或 `;` 都行；关键字后必须留空格（`否则 xxx`、`为 xxx`）。
- 注释三种：`//` 行注释（`p6.txt` ✓）、`'` 单引号行注释（`p5.txt` ✓）、`/* … */` 跨行注释（`p6.txt` ✓）。bas-1/bas-3 三种都用到了。

### 1.6 bas-1.txt 真实输出（BUILD_OK）
```

全局数=100 局部数=7
全局文本
程序 加法(3,4) = 7
函数 乘法(6,7) 大括号体 = 42
  显示() 收到参数 = 42
分号和换行都是语句分隔符 a=1 b=2 c=3
全局数 加一 后 = 101
加法() 省略实参 = 2453504 （形参默认值不生效，是垃圾值）
```

## 2. 变量类型全表与赋值转换（bas-2.txt）

### 2.1 类型表（文档第二节；实测能声明并打印的已标 ✓）

| 中文名 | 英文名 | 字节 | 实测 |
|---|---|---|---|
| 布尔 | Bool | 1 | ✓ 真打印为 1 |
| 字符 | char/sbyte | 1 | ✓ -3 |
| 字节 | byte/uchar | 1 | ✓ 200 |
| 短数/整形 | short | 2 | ✓ 1234 |
| 正短/正数 | ushort/word | 2 | ✓ 60000 |
| 整数 | int/dword | 4 | ✓ -123456 |
| 文本 | string | 缓冲区 | ✓ 见 §6 |
| 小数/浮点 | single/float | 4 | ✓ 但 `%f` 打不出来（见 §7） |
| 双精 | Double | 8 | ✓ `%f` 正常 |
| 日期 | datetime | 8 | 仅声明（`0@2018-8-15 12:00` 写法）未单独打印验证 |
| 大数 | long/ulong | 8 | 能声明，但**运算按 32 位截断**（见下） |
| 变数 | VARIANTNUMBER | 4/8 | ✓ 7 |
| 结构/数据表/对象/变体类 | — | — | 本笔记范围外 |

**大数实测**：`大数 大=2000000; 大=大*5000;` 期望 10,000,000,000，实际打印 `1410065408`（= 0x540BE400，32 位回绕）。基线：字面量 `大数 大=9000000000;` 直接 `内部错误 -> Overflow`。
→ **本版不要指望 64 位整数运算。**

### 2.2 `=` 是「按左边类型转换后写入」
- `整数 数=7,数三=2; 小数 商=数二/数三;` → 拼接输出 `整数相除赋给小数 = 3.500000`（bas-2 实测）。所以「左边是小数就按浮点算」这条文档描述**成立**（之前用 `%f` 打印得到 0.000000 是打印环节的坑，不是运算的坑）。
- `双精 双商=数二/数三;` → `%f` = `3.500000`。
- **小数→整数 是数值取整且是「四舍六入五成双」**（banker's rounding，实测 `z5.txt`）：
  `1.4→1`、`1.5→2`、`1.6→2`、`2.5→2`、`-1.5→-2`。bas-2 输出 `小数 1.5 转整数 = 2`。
- **不要直接把小数变量塞给 `%d`**：那打印的是 IEEE754 位模式（实测 `y9.txt`：1.4→`1068708659`、1.5→`1069547520`、1.6→`1070386381`、-1.5→`-1077936128`）。先赋给整数再打印。
- 冒号 `:` 触发浮点运算：`数二=:数二-数三;` 实测 `7-2=5`（整数运算加了冒号结果不变，bas-2 输出 `-> 5`）。文档用法 `数一=:数一-数二`。
- 文本拼接自动把数字转文本：`缓冲=缓冲+"结果:"+数二;` → `结果:5`（bas-2）。
- 字符/文本的字面量数字写法：`整数 数=$0D0A;`（十六进制，实测 3338）、`0x0D0A` 同值、`0#中国` 取 4 字节编码值、`\A` 取单字符编码 65（见 §3）。

### 2.3 文本缓冲区语义（重点）
- `文本 名[n];` 里 **n 只是「声明容量」**：`.长度` 成员返回 n；实际写入可以超过 n 并自动扩容（文档说预分配约 64KB）。
  实测 bas-7：`文本 缓冲[8];` 之后 `缓冲=缓冲+"12345678901234567890";` → `.长度=8`，`文字长度(缓冲)=20`，`写文字(缓冲)` 完整打印 20 个字符。
- `文字长度()` 数的是**字节数**（实测 k3.txt：`文本 缓冲(16)` + `内存复制(缓冲,"极语言",7)` → `文字长度=6`，3 个汉字×2 字节）。
- **`文本` 缓冲区不会自动清零**：未初始化（或扩容后）的内容可能是别的数据残渣。
  实测 bas-7 第一版：`大缓冲=大缓冲+"转小数…"` 打印出 `901234567890转小数(12.34) = 12.340000`（前面粘了别的缓冲区的残留）；加一句 `大缓冲(0)=0;` 之后输出变成干净的 `转小数(12.34) = 12.340000`。
  → **拼接/写入前先 `缓冲(0)=0;`（或 `清零`/`内存复制`）**。
- 文本可以像一维字节数组一样按偏移读写：`字节 码=内容(2);`、`内容(2)=\A;`（写 1 字节）、`内容(2)%=\好;`（写 2 字节）（bas-7 实测，见 §6）。

### 2.4 文本字面量赋值 = 致命 bug（重要）
| 写法 | 结果 |
|---|---|
| `文本 缓冲[64];` 全局 + `缓冲="abc";`（在例程内执行） | **卡死**（`t1.txt` 两次 TIMEOUT） |
| `文本 本地[32]="abc";`（在例程内声明） | **卡死**（`t6.txt`） |
| `文本 全局文本[32]="全局";`（全局声明处带初始值） | **正常**（bas-1/bas-2/p8/n1 全部正常） |
| `缓冲=缓冲+"abc";` | 正常（`t3.txt` → `abc`） |
| `缓冲=""+"abc";` | 输出 `0abc`（空字面量被当成整数 0，**别用空串做左操作数**） |
| `内存复制(缓冲,"abc",4);` | 正常（`t4.txt` → `abc`，字节数要含结尾 0） |
| `整数 针="abc"; 写文字(针);` | 正常（`t5.txt` → `abc`，字面量本身就是指针） |

→ 规则：**只在全局声明行给文本变量写初始值；运行期一律用 `缓冲=缓冲+"…"` 拼接 / `内存复制` / 整数指针。**

## 3. 转义符号与标点（bas-3.txt）

### 3.1 转义实测结果（**与文档不符的地方已标注**）

| 写法 | 实测结果 | 结论 |
|---|---|---|
| `"A\r\nB"` | 真实换行（y1b.txt → `AA`/`BB`） | ✓ 可用 |
| `'\r'` | 回车（n2.txt 输出空行） | ✓ 可用 |
| `'\n'` | 换行 | ✓ 可用（`写字符(10)` 是最稳的换行手段） |
| `"tab[\t]end"` | 原样输出 `tab[\t]end` | ✗ **文档说有，实测不转义**（y1c.txt） |
| `"a\\b"` | 原样输出 `a\\b` | ✗ **反斜杠不转义**（y1e.txt） |
| `"quote[a''b]end"` | `quote[a"b]end` | ✓ **两个单引号 `''` 表示一个双引号**（y1d.txt） |
| `"6quote\"end"` | 编译报 `未定义的名称:end` | ✗ `\"` 不是转义，会提前结束字符串（o7.txt） |
| `"china[0#中国]end"` | 原样输出（字符串里不求值） | ✓ 行为符合预期（y1f.txt） |
| `'\0' '\1' '\2'` 作为参数 | 输出只有一个 `?`、行为异常 | ✗ 不可靠，别用（y1.txt） |
| `\A`（表达式位置） | 65 | ✓ 取单字符编码值 |
| `0#中国` | -88485674（= GBK 字节 D6 D0 B9 FA 小端 int32） | ✓ 取两个汉字编码值 |
| `0$abcd` | 1684234849（= `abcd` 小端） | ✓ 取四个英文编码值 |
| `$0D0A` / `0x0D0A` | 都是 3338 | ✓ 十六进制 |
| `$0D0A & 255` | 10 | ✓ 取低字节 |

**标点速查（本笔记实测过的）**
- `'` 行注释、`//` 行注释、`/* */` 跨行注释。
- `''` → 双引号；`"` 包裹文字内容。
- `$` 十六进制 / 前缀二进制文本；`0x` 十六进制。
- `\` 取单个文字编码值；`0#` 汉字编码值；`0$` 英文编码值；`0@` 日期数值。
- `:` 触发浮点运算 / `返回(:…)` 返回小数值。
- `[ ]` 数组长度、编译期求值、指针偏移读写；`( )` 调用与下标；`{ }` 代码段。
- `@` 取地址/传函数地址（如 `开启线程(@自动写字,…)`，见官方示例）。
- `%`/`&` 后缀 = 按 2/4 字节读写内存（§6）。
- `0:192.168.1.1`（IP/颜色/键值转整数）——**未验证**。
- 文档标点表里的 `||` `&&`（多条件）**实测不可用**：`如果((a>1)&&(b>1))` 报 `初始启动 语法有误`（u1.txt）；`而且`/`或者` 也未通过（k2.txt 报语法错误）。

## 4. 运算符（bas-4.txt）

### 4.1 实测可用 / 不可用清单

| 类别 | 写法 | 实测 |
|---|---|---|
| 算术（符号） | `+ - * /` | ✓ `9 5 14 3`（整数除法取整） |
| 算术（中文） | `加 减 乘 除` | ✓ 同上 |
| 取模 | `数 余 值` | ✓ `7 余 2 = 1`；**`a%b` 会让编译器内部错误、`a%=2` 卡死**（主 agent 实测），一律写中文 |
| 位运算（中文） | `或 与 异 反 非 右移` | ✓ **变量操作数必须用中文**：`数 或 值=7 数 与 值=2 数 异 值=5 反 数=-8 非 数=0 数 右移 值=1` |
| 位运算（符号） | `\| & ^ ~ >> <<` | **只在字面量操作数时可用**：`1\|2=3 1&3=1 1^3=2 ~1=-2`、`8>>1=4 1<<3=8`；把变量写成 `数\|值` 直接报 `初始启动 语法有误`（s1.txt） |
| 复合赋值 | `乙+=5` | ✓ 10→15 |
| 省略等号 | `乙-3; 乙*2;` | ✓ 15→12→24 |
| 比较 | `= != <> > >= < <=` | **只能在条件位置**（如果/判断/循环/如果是）：`如果(数>值)`/`>=`/`<>`/`!=` 各自成立；`如果(数=值)` 正确判不相等 |
| 比较当表达式 | `整数 甲=数>值;`、`写格式("%d",数>值)` | ✗ 报语法错误（k1/k5.txt） |
| 逻辑与或 | `&& \|\|`、`而且 或者` | ✗ 实测报语法错误（u1/k2.txt），**未验证可用替代**：多层 `如果` 嵌套 |
| 优先级 | `1+2*3=7`、`(1+2)*3=9` | ✓ 小括号内是常规优先级 |
| 浮点函数 | `(表达式)绝对值/余弦/正弦/平方根/正切/反正切` | **未验证** |
| 中文比较词 | `数 大于 值`、`数 等于 值` | ✗ `未定义的名称:大于 / 等于`（n3 实测两边都失败） |

### 4.2 中括号 `[表达式]` = 编译期求值
- 文档第十三节：**中括号里的运算在编译期算完**；不加中括号就生成运行期运算指令。数组长度、结构长度必须是编译期常量。
- 中括号内可用 `+ - * / | & ! ^ ~`（`~` 在中括号里是**乘方**，不是取反）。
- **中括号里的表达式按从左到右顺序算，不是先乘除后加减**：`[甲+乙*2]` 其中甲=1、乙=2 → `6`（不是 5）；`[6+[35-12]*150-[60/12]]` → `4345`（= ((6+23)*150)-5）。bas-8 实测。
- 中括号可以嵌套中括号，**不要嵌套小括号**（小括号会让它变成运行期指令）。

### 6.1 声明的两种括号，能力不同（实测）
| 写法 | 说明 | `.长度` 成员 |
|---|---|---|
| `整数 数组[8];` / `整数 表[3,4];` | 固定长度（方括号） | ✓ 可用（a1=8、z1 表=3） |
| `整数 数组(5);` | 固定长度（圆括号，官方示例常用） | ✗ `未定义的名称:数组.长度`（u4.txt） |

- **`整数 甲[8]={1,2,3,4,5,6,7,8};` 这种「方括号 + 初始化列表」组合不可靠**：`o4.txt`/`n5.txt` 报 `未知的数组类型：甲`；`x3c.txt` 能编过；bas-7 第一版编过了但**数据是垃圾**（`数列(0)=842084409`）。

## 7. 专题：小数/浮点/双精 如何正确转成文本输出（bas-8.txt）

### 7.1 问题根因
`写格式` 就是 C 的 `printf`，`%f` 要求栈上是 **8 字节 double**。
本版里：
- `小数` / `浮点` 是 **4 字节 float** → 传给 `%f` 时只压了 4 字节（或压了地址），printf 读到的是错的 8 字节 → 打印 `0.000000`。
- `双精` 是 **8 字节 double** → `%f` 正常。
- 带 `#` 后缀的字面量（`3.5#`）是 double → `%f` 正常。

### 7.2 实测对照（bas-8.txt，BUILD_OK）
```
  小数变量 单 %f -> 0.000000   <-- 错
  浮点变量 浮 %f -> 0.000000   <-- 错
  双精变量 双 %f -> 3.125000   <-- 对
  双精字面量 3.5# %f -> 3.500000   <-- 对
```

### 7.3 四种可靠写法（全部实测）
```ji
// 写法 A（最通用，任何浮点类型都行）：拼进文本，再用 写文字() 输出
缓冲(0)=0;                       // 先清缓冲区，见 §2.3
缓冲=缓冲+"小数="+单;             // → 小数=1.500000   （默认 6 位小数）
写文字(缓冲);

// 写法 B：格式化() 写进文本，再 写文字()
格式化(缓冲,"  格式化 %.4f",双);  // → 格式化 3.1250
写文字(缓冲);

// 写法 C：先把 小数/浮点 赋给 双精，再 %f
双精 提升=单;
写格式("[4] %f\r\n",提升);        // → 1.500000

// 写法 D：本来就是 double 的时候直接 %f
写格式("%f\r\n",双);              // → 3.125000
写格式("%f\r\n",3.5#);            // → 3.500000
```
bas-8 实测输出：
```
[2] 推荐写法A：拼进文本再 写文字()
  小数=1.500000
  浮点=2.250000
  双精=3.125000
[3] 推荐写法B：格式化() 写进文本再 写文字()
  格式化 3.1250
[4] 先把 小数 赋给 双精 再 %f -> 1.500000   <-- 对
```
另：**拼接出来的浮点文本默认 6 位小数**（`1.500000`、`2.250000`、`12.340000`）；要指定精度用 `格式化(buf,"%.Nf",双精)`。

### 7.4 `写格式`（printf）格式串规则（bas-8 实测）
```
%d  十进制有符号整数        → %d=255
%u  十进制无符号
%f  浮点数（见上：只对 double 有效）
%s  字符串（**只接字面量**；传文本变量会卡死，请用 写文字）
%c  单个字符                → %c=A
%x/%X 十六进制              → %04X=00FF
%o  八进制                  → %o=10
%p  指针                    → %p=00001000
%e  指数形式                → %e=1.234550e+004
%-  左对齐   %0 前导零填充   %N 占位宽度   %.N 小数位/截断
  [%-5d]=[7    ] [%05d]=[00007] [%5d]=[    7]
%#x → 0x 前缀；%.*s 用变量指定长度；`%%` 输出一个字面百分号
```
bas-8 实测输出：
```
[5] 写格式 的格式串规则
  %d=255
  %04X=00FF  %o=10  %p=00001000
  [%-5d]=[7    ] [%05d]=[00007] [%5d]=[    7]
  %c=A  %e=1.234550e+004
  %s 只接字面量: hello
```
- `写格式("%s", 文本变量)` → **卡死**（技能笔记与 d5.txt 一致）；文本变量一律 `写文字(变量)`。
- 格式串里的 `|`、`&` 只是普通字符，没问题。
- `写格式` 的返回值 = 打印的字符数（会变成 `结束` 的退出码）。

### 7.5 第十三节 常量（bas-8 实测）
```ji
常量 甲=1,乙=2,丙=3;         // 逗号连写
常量 红=0x10,蓝=0x20;
常量 样式=[甲+乙*2];         // 中括号 = 编译期求值，按顺序算 → 6
常量 位组合=[红|蓝];         // → 48
写格式("%d\r\n",[6+[35-12]*150-[60/12]]);   // → 4345
```
- 常量值可以按位组合（`[确定取消|问号图标]` 这种），中括号里按顺序求值、`~` 在中括号内是乘方。
- bas-8 实测输出：
```

  常量 甲=1 乙=2 丙=3
  [甲+乙*2]=6 （中括号内按顺序算，不是先乘除）
  [红|蓝]=48
  [6+[35-12]*150-[60/12]]=4345
```

### 7.6 `定义`（宏/指令集）
- `定义 位数=32;`、`定义 后缀=com;` 作为配置行可用（o8.txt BUILD_OK，产物按配置生成）。
- `定义 平方值(x)=x*x;` 这种「宏程序」写法**实测失败**：编译产物不是合法可执行文件（跑的时候 .NET 报 `The specified executable is not a valid application for this OS platform`，o9.txt）。→ 宏程序**未验证可用**，指令集类 `定义` 属第八节范围，本笔记不涉及。

## 8. 陷阱总表（一条条都有实测证据）

| # | 陷阱 | 现象 | 对策 | 证据 |
|---|---|---|---|---|
| 1 | 源码用 LF 换行 | `内部错误 -> Invalid procedure call or argument [:第0行]` | 一律 CRLF | w2 vs w1 |
| 2 | 源码非 GBK | 关键字乱码 `未定义的名称:绋嬪簭绫诲瀷` | GBK/GB18030 | 技能笔记 |

## 10. 仍需澄清的疑点（未验证 / 不确定）

1. **偶发假死**：任何程序都可能第一次 TIMEOUT、第二次正常；bas-4 早期版本（含符号位运算 + 变量）100% 卡死且无输出，去掉后正常——**卡死的真实触发条件没有完全定位**（怀疑与「多个运算符表达式 + 多实参 写格式」组合有关）。用二分法拆小程序定位是可行手段。
2. `如果(...) 而且/或者 (...)`、`&&`/`||` 全部报语法错误 → **本版多条件组合的可用写法未找到**（嵌套 `如果` 是唯一确定可行的）。
3. `#` 注释符号、`?`（上次赋值结果）、`??`（纳秒）、`0:IP/颜色`、`读格式`/`读字符`（会等输入）、`字符处理`/`字符串函数`（`文字长度`已验，其余未验）、`浮点函数（余弦/正弦/平方根…）`、`传送`、`日期`类型的算术、`变体类` —— **未验证**。
4. 二维数组 `表(i)(j)` 的正确用法没搞清（文档写 `数三(3)(0)`，实测数值错乱）；`.维数` 到底返回第几维（实测 `整数 表[3,4]` → 长度=3、维数=4）与文档「维数=第一维长度」矛盾。
5. `循环数组` 十二种文档形式全部没跑通，**是否有可用写法未知**。
6. `重置/保留` 失败的真正原因（是否只对 `数据表`/子类数组有效）未查明。
7. `定义` 宏程序的正确语法未找到（`定义 名(x)=表达式` 产出非法可执行文件）。
8. 报错行号偏移量在不同文件里观察到 -1 与 -2 两种（配置行 + 空行是否都计入），需要更多样本确认。
