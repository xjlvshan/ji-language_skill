## 0. 本领域新增的通用坑（最重要的 6 条）

| 坑 | 现象（实测） | 对策 |
|---|---|---|
| **LF 换行** | `BUILD_FAIL: -> 内部错误 -> Invalid procedure call or argument [:第0行]` | 源码必须 CRLF。实测：同一份源码，LF → BUILD_FAIL，改成 CRLF → BUILD_OK |
| **入口必须是第一个 `程序`/`函数`** | 辅助函数写在入口前面 → `初始启动 语法有误` + 内部错误 | 全部辅助函数放到入口 `结束` 之后 |
| `文本 变量[32]="字面量";` | 程序**卡死/超时**（实测 5/5 次） | 用 `复制文字(变量,"文字")`、`加文字`、`变量="前缀"+数值`、`内存复制` |
| `信息框(0,...)` 需先导入 | 未导入 → `初始启动 语法有误` | 加 `导入 信息框 别名 MessageBoxA 支持库 "USER32.DLL",4;` |
| 注册表常量需 `advapi32.lib` | 缺 `引入 "lib\advapi32.lib";` → `未定义的名称:表键本机` | 用到 `表键*`/`查询值项`/`改子项值` 就加这一行 |
| 网络类型需 `ws2_32.lib` | 缺 `引入 "lib\ws2_32.lib";` → `未定义的名称:地址类` | 用到 `地址类`/`分配`/`连网` 就加这一行 |

补充实测：
- **`写格式("%s", 文本变量)` 可以工作**（实测 `复制文字(变量,"abc"); 写格式("s=[%s]",变量)` → `s=[abc]`）；但 **`写格式("%s", 结构体.文本字段)`（如 `项.名称`）会 `0xC0000000+791` 栈缓冲区异常崩溃** → 结构体里的文本字段一律用 `写文字(项.名称)` 输出。
- **把字符串字面量直接当指针实参**（如 `改子项值(...,"hello",@长度)`）会 0xC0000005 崩溃 → 先 `复制文字(文本变量,"hello")` 再传变量。
- **`写控制台(句柄,...)`（WriteConsoleA）在标准输出被重定向时会卡住/崩溃**（实测：直接运行到真实控制台窗口时能写出；被 `ProcessStartInfo.RedirectStandardOutput` 重定向时挂起）→ 批处理场景统一用 `写文字/写格式/写字符`。
- 程序若**不调用 `退出(0)`**，极语言的 stdio 缓冲不会刷新，`-Run` 抓不到任何输出（`[TIMEOUT]` 且无内容）。**每个示例都以 `退出(0)` 结束**。
- 数字/文本变量在多个 `写格式` 之间**不会自动换行**；`写文字` 自带换行、`写字符(10)` 手动换行。要把「标签 + 数字」拼一行，用 `写格式("标签=%d",值);写字符(10);`。

### 1.4 命令行颜色 vs 改字属性

- `命令行("color 5A")` 改的是**整屏**前景/背景（5A = 紫底亮红字），`sec.clean.txt` 说明：背景色在高位、文字色在低位。
- `改字属性(输出,颜色)` 只影响**之后写入**的字符，从而实现多色一行（官方 `控制台彩字.sec` 就是这个思路：`循环{延时;改字属性(输出,颜色);写控制台(输出,字,2);颜色+2}`）。

## 2. 信息框 / 消息框 / 延时框（`sys-2.txt`）

### 2.1 必须先导入

```极语言
导入 信息框 别名 MessageBoxA 支持库 "USER32.DLL",4;
导入 延时框 别名 MessageBoxTimeoutA 支持库 "USER32.DLL",6;
```
参数含义（`支持库 "DLL",N`）：N = 参数个数。未导入就写 `信息框(...)` → `初始启动 语法有误 [:第N行]`（实测）。

### 2.2 按钮常量（`sec.clean.txt` 2377–2415）

| 中文 | 值 | 中文 | 值 |
|---|---|---|---|
| 确定取消 | `$1` | 错误图标 | `$10` |
| 中止重试 | `$2` | 问号图标 | `$20` |
| 是否取消 | `$3` | 惊叹图标 | `$30` |
| 弹出是否 | `$4` | 信息图标 | `$40` |
| 重试取消 | `$5` | 用户图标 | `$80` |
| 弹出系统 | `$1000` | 弹出任务 | `$2000` |
| 帮助按钮 | `$4000` | 弹出置前 | `$10000` |
| 弹出置顶 | `$40000` | 文字居右 | `$80000` |

**返回值**：选了确定 1 / 选了取消 2 / 选了中止 3 / 选了重试 4 / 选了忽略 5 / 选了是 6 / 选了否 7 / 选了关闭 8 / 选了帮助 9。

**实测（sys-2.txt）输出节选**：
```

信息+弹出是否=$44
延时框 返回=32000 (32000=超时自动关闭)
```
→ 图标/按钮用 `+` 组合（`$20+$1=$21`），与 Win32 的 OR 完全一致。

### 2.3 阻塞问题（重要）

**实测**：`导入 信息框...; 信息框(0,"内容测试","标题测试",$40);` 在 `-RunSeconds 3` 下**超时被杀**，且前面 `写文字("before")` 的输出也没刷出来 —— 因为控制台程序窗口在后台、stdout 被重定向，无人能点击按钮。
**另一个实测**：用 `开启线程(@关闭框,0,0)` + `FindWindowA` + `SendMessageA(窗,$10,0,0)` 想自动关框，同样 **10 秒超时**（`Closing` 会连带结束进程导致我这边也测不到返回值）→ **信息框的返回值未验证**。

**结论与对策**：
1. 批处理/自动化里**不要调用 `信息框`**；
2. 需要弹提示用 **`延时框`**：`延时框(0,"内容","标题",[样式],0,毫秒)`，到点自动关闭，**超时返回 32000**，不阻塞（实测 `延时框 返回=32000`）；
3. GUI 程序里 `信息框` 正常（官方 `文件读写.sec`/`注册表.sec` 都用它）。

### 3.2 `查找文件类`（FINDDATA, 318 字节）

成员：`属性 / 创建时间 / 创建高位 / 最后访问 / 访问高位 / 最后修改 / 修改高位 / 大小(nFileSizeHigh) / 长度(nFileSizeLow) / 预留1 / 预留2 / 名称 / 备用名`。

- ✅ **文件大小读 `.长度`（低 32 位）**，`.大小` 是高 32 位（文档给的中文名极易误用）。
- ✅ **声明建议 `查找文件类 项(长度=318);`**（官方 `进程.sec` 就是 `进程类 进程(长度=296)` 这种写法）。
- ✅ 循环写法（照官方 `遍历.sec`）：
```极语言
下个=1;
位置=查找文件("sys3_*.txt",项);
循环{
    写格式("  #%d 名称=",总数);写文字(项.名称);
    写格式("     长度=%d 属性=0x%X",项.长度,项.属性);写字符(10);
    总数++;
    下个=下个文件(位置,项);
}(下个=0);
关闭查找(位置);
```
**实测（sys-3.txt）输出节选**：

- ⚠️ **坑（实测）**：当目录里有 **60+ 个 `.txt`**、用 `查找文件("*.txt",项)` 全量枚举时，程序在枚举过程中 `0xC0000409`（STATUS_STACK_BUFFER_OVERRUN）/ 挂起；而同样代码用 `"zz*.txt"`（2 个文件）跑完全正常。**结论：枚举大批文件的稳定性存疑，实用程序请用窄通配或限制次数**（`m9.txt` 单独跑 `"*.txt"` 时能列全 65 个并正常退出，说明与「前面已执行的文件/内存操作」叠加时才触发）。

### 3.3 读写真实文本文件

**实测（sys-3.txt）**：`建文件("sys3_test.txt",0)` → 写入 `line1 hello\r\nline2 world\r\n`（26 字节，`\r`=13 `\n`=10 用 `写字符` 逐字节加）→ 重新 `开文件(...,0)`：`流定位(0,2)=26`、定位到 6 读 5 字节得 `hello`、定位 -6 读 6 字节得 `orld\r\n`。

> `文件=开文件(件名,0); 长度=文件大小(文件,@内容); 内容=申请内存(长度+1); 读文件(文件,内容,长度); 关文件(文件); 内容(长度)=0;`
