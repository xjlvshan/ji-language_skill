# 06 · GUI（窗体与控件）实测笔记

来源：`D:\SEC\inc\GUI.inc` 源码逐行阅读 + 官方示例（`code\遍历.sec`、`计算器.sec`、`任务栏.sec`、`拖曳文件.sec`）+ 实测编译运行与截图验证。

## 1. 最小可用骨架（实测：编译 BUILD_OK，窗口与控件正常显示）

```
模块文件=GUI.inc
整数 窗体,标签1,按钮1,编辑1;
程序 加载窗体
窗体=创建窗口($100,程序.名称,"窗口标题",$10C80000,100,100,520,340,0,0,0,0);
标签1=创建窗口($0,"Static","骨架已启动",$50000000,20,20,470,40,窗体,1,2,0);
按钮1=创建窗口($0,"Button","点我",$50000000,20,80,150,32,窗体,2,3,0);
编辑1=创建窗口($200,"Edit","初始文字",$50010000,20,130,470,26,窗体,3,4,0);
读取消息
结束
程序 窗体消息(窗口,消息,参数,数据)
判断(消息)
为 窗口关闭{停止(0)}
为 单击左键{改控件字(窗体,3,"控件编号="+参数 & $FFFF)}
否则{处理窗口(窗口,消息,参数,数据)}
结束
```

- **入口不用自己写**：`GUI.inc` 里已经定义 `程序 程序入口`（做 `注册窗类/窗口边界/加载窗体`）和 `程序 读取消息`（消息循环 `获取消息/翻译消息/分派消息`）。你只需要提供 `程序 加载窗体` 和 `程序 窗体消息`。
- `程序 加载窗体` 里建完窗口后调用 `读取消息` 进入消息循环。
- `程序 窗体消息(窗口,消息,参数,数据)` 是窗口过程；`否则{处理窗口(窗口,消息,参数,数据)}` 做兜底。
- ★ `判断(...)` 链**不要自己写 `结束`**（见 `02-language-core.md`），由 `窗体消息` 的 `结束` 收尾。

## 2. 不要重复声明 GUI.inc 已有的名字（实测警告）

`GUI.inc` 顶部已声明：

```
窗口类 界面(风格=$8B,背景=6)  消息类 消息;
矩形类 桌面;  常量 实例=$400000, 程序.名称="SecClass";
```

实测在用户代码里再写 `常量 实例=$400000;` / `窗口类 界面...` / `消息类 消息;` / `矩形类 桌面;` 会得到编译提示：`已存在常量名:实例`、`已存在变量名:界面/消息/桌面`（能编译通过，但应避免）。也不要自己写 `程序 程序入口`。

## 3. `创建窗口` 参数（按官方示例与实测归纳）

```
窗口 = 创建窗口(类型, 类名/标题, 标题, 风格, 左, 上, 宽, 高, 父窗口, 编号, 控件类型码, 实例)
```

| 位置 | 含义 | 实测/示例取值 |
|---|---|---|
| 1 | 窗口类型 | `$100` 主窗口、`$200` 编辑框/列表框等、`$0` 按钮/静态（官方示例混用，功能上都能建出来） |
| 2 | 类名 | 主窗口用 `程序.名称`（=已注册的 `SecClass`）；控件用系统类名 `"Button"` `"Edit"` `"Static"` `"listbox"` |
| 3 | 标题文字 | 支持 `&O` 形式的 Alt 快捷键（文档） |
| 4 | 风格 | 主窗口 `$10C80000`；按钮/静态 `$50000000`；编辑框 `$50010000`/`$50010004`；列表框 `$50210081`/`$50200001` |
| 5–8 | 左 上 宽 高 | 居中常用 `左=(桌面.宽-宽)>>1`（`矩形类 桌面` 由 `窗口边界(桌面窗口,桌面)` 填充） |
| 9 | 父窗口 | 主窗口句柄；主窗口写 `0` |
| 10 | 编号 | **控件 ID**（事件里用 `参数` 传回），主窗口写 0 |
| 11 | 控件类型码 | 实测 `2`=静态/标签、`3`=按钮、`4`=编辑框、`9`=列表框 |
| 12 | 实例 | `0`（官方示例一致） |

## 4. 消息与事件（实测 + 文档 `窗口消息` 表）

- `判断(消息)` 常用分支：`窗口关闭`(`$0010`)、`单击左键`（控件被点击/命令事件，**③参数低位=控件编号，高位=通知码**）、`绘制按钮`(`$0135`)、`绘制静态`(`$0138`)、`键盘按下`(`$0100` WM_KEYDOWN，参数=虚拟键码)、`释放左键`(`$0202`)、`定时事件`(`$0113` WM_TIMER，参数=编号)。
- 实测验证：`gui-1` 中点击编辑框时编辑框显示 `控件编号=3 通知码=768`（`参数 & $FFFF` = 3，`参数>>16` = 768）。
- 富控件通知走 `控件事件`（`$004E` WM_NOTIFY），在事件过程里用 `公共事件(数据)` 解包：`数据` 前三项 = 窗口、编号、事件；事件码：`-1` 内存不足、`-2` 单击左键、`-3` 双击左键、`-4` 按下回车、`-5` 右键单击、`-6` 右键双击（文档 12453 行、3671 行）。
- 完整消息常量表：`docs/sec.clean.txt` 第 3030–4130 行（`窗口关闭=$0010`、`命令事件=$0111`、`控件事件=$004E`、`拖放文件=$0233` 等）。

## 5. 控件读写与界面辅助（实测可用）

| 写法 | 作用 |
|---|---|
| `改控件字(窗体,编号,文本)` | 设置控件文字（gui-1 实测有效） |
| `取控件数(窗体,编号)` / `改控件数(窗体,编号,值)` | 直接读写控件里的数字（文档，免缓冲转换） |
| `格式化(缓冲,"格式",参数...)` | 按格式写入文本缓冲，再喂给 `改控件字` |
| `发送消息(控件,消息,参数,数据)` | 通用；常用消息常量：`列表添加`、`列表附加`、`列表选项`、`列表数据`、`列表清除`、`编辑替换`、`指定字体` |
| `新建字体(逻辑字体类)` + `发送消息(控件,指定字体,字体,0)` | 控件字体（计算器示例在 `绘制按钮` 消息里统一设置） |
| `文本改色(参数,颜色)` / `改背景色(参数,颜色)` | 在 `绘制*` 消息里改文字/背景色 |
| `内容~控件` / `控件~内容` | 文档提到的文本控件快速读写符号（本版未实测） |
| `拖曳文件` 消息 + `查询拖曳/释放拖曳` | 文件拖放（官方 `code\拖曳文件.sec`） |

## 7. 常见坑

- 自己写 `程序 程序入口` 或在 `加载窗体` 之前定义其它 `程序` → 入口被抢（见 `02-language-core.md`），窗口不出现或行为异常。
- `判断` 链写了 `结束` → 后面的代码（含控件消息过程）失效。
- `文本 变量[32]="字面量";` → 死循环（改用 `内存复制` 或直接传字面量给 `创建窗口/改控件字`）；★ 加 `定义 位数=64;` 也能救（见 `02-language-core.md` §7）。
- 控件 ID 必须唯一且与 `窗体消息` 里判断的编号一致；`2`=按钮、`3`=编辑框（按你 `创建窗口` 第 10 参设定）。
- 忘记 `读取消息` → 窗口一闪而过/无响应。

## 8. GUI 领域追加实测（agent 实测 + 主 agent 复验；示例 `examples/12-gui-*.txt`）

### 8.1 骨架补充

- `GUI.inc` **不包含** `加载窗体`，必须自己写；写了它就能跑，**不必**写 `程序 程序入口`（GUI.inc 已提供）。
- `实例 / 界面 / 消息 / 桌面` 已被 GUI.inc 声明，重复声明会刷 4 条 `已存在…` 警告。
- GUI 源码同样**必须 GBK + CRLF**（LF → `内部错误 Invalid procedure call or argument [:第0行]`）。

### 8.2 `创建窗口` 12 参（修正）

```
创建窗口(类型, 类名, 标题, 风格, 左, 上, 宽, 高, 父窗, 菜单/控件ID, ?, ?)
```

- **第 10 参 = 控件 ID**（agent 用 `GetDlgCtrlID` 实测一致；顶层窗口该位置是菜单句柄）。
- 第 11/12 参语义未定：写 `0/2/3/4/9/22` 都能正常建出控件（本技能 `07-gui-minimal.txt` 用 `…,窗体,1,2,0)` 实测窗口与控件正常）。

### 8.3 事件参数编码（实测）

- `单击左键`（WM_COMMAND `$0111`）的 **参数 = 通知码 << 16 | 控件 ID**。
  例：按钮点击 `2`（通知码 0）；编辑框获得焦点 `0x3000002`（通知码 `0x300`）。
- 通知码表：按钮 `BN_CLICKED=0 BN_DOUBLECLICKED=5 BN_SETFOCUS=6 BN_KILLFOCUS=7`；编辑框 `EN_SETFOCUS=$100 EN_KILLFOCUS=$200 EN_CHANGE=$300`；列表框 `LBN_SELCHANGE=1 LBN_DBLCLK=2 LBN_SETFOCUS=4`；组合框 `CBN_SELCHANGE=1 CBN_DBLCLK=2 CBN_SETFOCUS=3`（完整常量表见 `examples/13-aux-1.txt`，可直接跑）。
- ★ **坑**：`判断(参数 & $FFFF)` 直接写会 `语法有误+内部错误`（变量不能直接用符号位运算）。必须先 **`整数 编号=参数 & 65535;`** 再判断/使用。
- 菜单项编号从 **1001** 开始（`创建菜单` / `附加菜单`，实测点击命中）。
- 组合框内部自带一个 Edit 子窗口（`GetDlgCtrlID` 返回 1001），枚举子窗口会多一个。

### 8.4 控件读写（含一处被推翻的说法）

- ✅ **`改控件字(父窗体, 控件ID, 文本)` 对 Edit 也有效**：主 agent 复验 `examples/12-gui-5-edit-settext.txt` → 截图 `12-gui-5-edit-settext-shot.png` 显示编辑框内容被改成「改控件字后来设置」。（GUI 领域曾报告 Edit 改不动，**未能复现**，以本复验为准。）
- `改控件字(...,"字面量"+整数)` 拼接可能无效 → 先用 `格式化(缓冲,"…%d",值)` 再传缓冲。
- `取控件字`/`取控件数`/`改控件数` 读写控件文字与数字（文档 331–336 行）。

### 8.5 定时器 / 菜单 / GDI（agent 实测）

- 定时器：**`设置定时器` 不是本版符号**（语法有误）→ 用 `设置定时(窗口,编号,毫秒,@回调)`，`毫秒=0` 删除；回调收到的编号实测恒为 0（疑点）。`定时事件` = `$0113`。
- GDI：`取设备` 拿 DC → `画方块/画椭圆/圆角矩形/画线/写字到`；**`圆角矩形` 没有「画」前缀**（`画圆角矩形` 语法有误）；颜色用 **COLORREF=`$BBGGRR`**；字体 `逻辑字体类` → `新建字体` → `选择对象` 生效（截图 `probe40.png`）。
  注意：在客户区自绘会**盖住子控件**；`绘制文本(DrawTextA)` 实测画不出内容（疑点）。
- 进度条：定时器回调里发 `进度步进`(PBM_STEPIT) 会崩溃 → 改用 `进度取值`→`进度位置`。
- 风格常量：`D:\SEC\inc\风格.txt` 是设计器风格名 → 十六进制表（无 `$` 前缀）；常用：

  | 用途 | 值 |
  |---|---|
  | 主窗口 | `$10C80000` |
  | 按钮/静态 | `$50000000` |
  | 编辑框 | `$50010000` / `$50010004` / `$50810002` |
  | 列表框 | `$50210081` / `$50200001` |
  | 组合框 | `$50016009` |

### 8.6 字符串坑（GUI 领域发现，通用）

- 极语言字符串**不支持 `\"` 转义**：写 `"统计\"x\""` 会报 `未定义的名称:统计` 之类 → 需要引号时改用 `\` 的等价写法（如用 `''` 表示 `"`，bas 领域实测 `''`→`"`）或分开拼接。
