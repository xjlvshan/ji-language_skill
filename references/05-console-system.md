# 05 · 控制台 · 系统 · 文件（实测笔记）

来源：本机实测 + 官方文档 `docs/sec.clean.txt`（第十六节 控制台起）与 `docs/lib.clean.txt`（C 运行库中文函数表）。每条标注验证状态。

## 1. 控制台程序骨架

```
程序类型=2
模块文件=CMD.inc
程序 初始启动
写文字("hello");
结束
```

- `程序类型=2` = 命令控制台；产物 `.com`（真 32 位 PE）。
- `模块文件=CMD.inc` 提供 C 运行库符号；缺它会报 `符号 写文字 不存在.`。
- 入口必须是文件里第一个 `程序`（见 `02-language-core.md`）。

## 2. C 运行库函数（`CMD.inc`，实测可用）

| 中文名 | C 名 | 用法 | 备注 |
|---|---|---|---|
| 写文字 | puts | `写文字("文字");` | 自动补换行；**文本变量**也可传（`写文字(文本变量)`） |
| 写字符 | putchar | `写字符(65);` | 写一个 ASCII 字符 |
| 写格式 | printf | `写格式("a=%d s=%s\r\n",a,s);` | `%d %s %x %X %o %u %c %%` 正常；**`%f` 传浮点字面量会输出 0** |
| 读字符 | getchar | `读字符` | 会阻塞等待输入（自动化测试里不要调用） |
| 读文字 | gets | `读文字(内容);` | 同上 |
| 读格式 | scanf | `读格式("%d",@值);` | 同上 |
| 命令行 | system | `命令行("title 我的程序");` | 执行 CMD 命令 |
| 延时 | Sleep | `延时(500);` | 毫秒，实测编译运行通过 |
| 内存复制 | memcpy | `内存复制(目的,源,字节数);` | 给 `文本` 缓冲区写字面量的**推荐方式** |
| 内存传送 | memmove | `内存传送(目的,源,n);` | 允许重叠 |
| 申请内存/申零内存/保留内存/释放内存 | malloc/calloc/realloc/free | `整数 m=申请内存(1024); 释放内存(m);` | |
| 填充内存 | memset | `填充内存(内容,0,n);` | |
| 查找文字/文字复制/前字复制/查字符 | strstr/strcpy/strncpy/strchr | `位置=查找文字(文字1,文字2);` | |
| 打开管道 | popen | `pp=打开管道(命令,"r");` | 可读写子进程控制台 |

★ 浮点输出正确姿势（实测）：

```ji
浮点 f=2.5;
文本 b[64];
b="f="+f;        // 数值→文本自动转换，浮点默认 6 位小数
写文字(b);        // → f=2.500000
```

## 3. 控制台 Win32 接口（文档 + 实测）

```ji
整数 输出=取控制台(标准输出);     // 标准输入=-10 标准输出=-11 标准错误=-12
改字属性(输出,12);               // 整屏字符颜色（高亮=底色/前景色组合，+8 为高亮）
写文字("亮红");
改光标位(输出,8*65536+30);       // 高 16 位=行，低 16 位=列
设置标题("我的控制台");           // SetConsoleTitleA，返回长度
获取标题(文本缓冲,长度);          // GetConsoleTitleA，返回实际长度
获取模式(输入,@模式); 设置模式(输入,模式|鼠标输入);
控制大小(输出,25*65536+80);      // 缓冲区 25 行 80 列
写控制台(输出,"文字",4);          // WriteConsoleA（长度按字节）
命令窗口 / 进程标识 / 开机毫秒 / 控制码页 / 输出码页   // 无参读取型接口
退出(0);                          // 结束进程并返回退出码（实测可用）
```

颜色属性（`lib.clean.txt` 控制台字符属性表）：`文本蓝色=1 文本绿色=2 文本红色=4 高亮=8`、`背景蓝色=0x10 背景绿色=0x20 背景红色=0x40`；所以 `12`=亮红、`0x70`=白底黑字（实测 sys-1 输出正常）。

> 更完整的控制台 API 清单（约 60 个：`控制游标/输出数据/读输出字/字格属性/伪控制台/控制事件…`）见 `docs/sec.clean.txt` 第 2693–2830 行，函数名即中文关键字。

## 4. 命令行参数（实测）

```ji
程序 初始启动
整数 行=启动参数;            // GetCommandLineA，返回命令行字符串指针
写格式("命令行=%s\r\n",行);
结束
```

实测运行 `app-baseconv.com 255` → 程序拿到 `"D:\...\app-baseconv.com" 255`，用逐字节扫描取到最后一个参数（见 `examples/04-app-baseconv.txt`）。
注意：`程序 初始启动(argc,argv)` 这种带参入口**不可用**（实测卡死）。

## 5. 文件读写（实测·推荐模板）

```ji
整数 h=开文件("data.txt",0);      // 0=读；写入用 建文件(名,0)
整数 高位=0;
整数 长度=文件大小(h,@高位);       // 返回字节数（高位接收高 32 位）
整数 内存=申请内存(长度+1);
整数 已读=读文件(h,内存,长度);
关文件(h);
内存(长度)=0;                      // 以 0 结尾，当作字符串用
// 按字节处理
整数 i=0,行数=1;
循环在(i<长度){ 如果(内存(i)=10){行数++;} i++; }
写格式("字节=%d 已读=%d 行数=%d\r\n",长度,已读,行数);
释放内存(内存);
```

实测：`examples/06-app-fileinfo.txt` 读取自身目录下 693 字节的源码文件 → `字节数=693 已读=693 / 行数=29 非空白字符=618`，并打印前 120 字节。

写文件（官方 `inc\文件内容.sc` 的写法）：

```ji
整数 文件=建文件("out.txt",0);
如果(文件>0){ 长度=写文件(文件,内容,长度); 关文件(文件); }
```

相关函数名（文档/官方示例）：`开文件`、`建文件`、`读文件`、`写文件`、`关文件`、`文件大小`、`流定位`、`文字长度`、`文件改名`、`创建目录/修改目录/删除目录`、`分区容量`。

### 5.1 目录遍历（实测跑通 ✅）

```ji
查找文件类 文件(长度=318)          // ★ 声明要带长度
程序 初始启动
整数 句柄=查找文件("*.txt",文件);   // 返回查找句柄（>0 有效）
如果(句柄>0)
{
  整数 个数=0;
  循环
  {
    写文字(文件.名称);              // 文件名；大小读 文件.长度（.大小 是高 32 位）
    个数++;
  }(下个文件(句柄,文件)=0)          // 0 = 没有更多
  关闭查找(句柄);
  写格式("共 %d 个文件\r\n",个数);
}
否则 { 写文字("没有找到文件"); }
结束
```

实测：`examples/11-app-filelist.txt` 在本目录列出全部 `*.txt` 并统计个数（验证时输出 `共 74 个文件`）。
注意：同一目录一次枚举 **60+ 个文件**可能 `0xC0000409` 崩溃或挂起 → 用窄通配（`"zz*.txt"`）分片枚举。

## 6. 网络（TCP 实测跑通 ✅）

★ 关键前提：**模块列表要带上 `dll.inc`**（它引入 `ws2_32.lib`），否则 `网络启动/分配/连网` 全部报 `语法有误`：

```
程序类型=2
模块文件=CMD.inc,dll.inc
```

最小可运行 TCP 连接探测（`examples/11-net-tcp-connect.txt`，实测输出 `连 127.0.0.1:3080 = 0`、`连 127.0.0.1:9 = -1`）：

```ji
文本 数据[400];
整数 启=网络启动($202,数据);        // WSAStartup，返回 0 = 成功
整数 网号=分配(2,1,6);              // socket(AF_INET, SOCK_STREAM, IPPROTO_TCP) → 句柄
文本 地址[16];                      // 手工拼 sockaddr_in（本版没有 地址类）
地址(0)%=2;                          // sin_family = AF_INET（2 字节写入）
地址(2)%=反转(端口);                 // sin_port = htons(端口)
地址(4)&=转换地址("127.0.0.1");      // sin_addr = inet_addr(ip)（4 字节写入）
整数 连=连网(网号,地址,16);          // connect：0 = 成功，-1 = 失败
关闭(网号);
网络终止;                            // WSACleanup
```

- `地址类 IP(协议=2)` 这种写法在纯文本单文件下报 `未定义的名称:地址类` → 用上面的 16 字节缓冲方案（官方 `inc\网络通讯.sc` 也是这么做的）。
- 端口扫描应用：`examples/11-app-netport.txt`（实测：3080/135/445 开放、3306/5432/8080 关闭）。
- 其它 Winsock 中文名（`发送/接收/绑定/监听/接受/异步通知/接口关闭…`）见 `docs/lib.clean.txt` 第 869–930 行以及官方 `inc\网络通讯.sc`、`code\连接测试.sec`、`code\内网聊天.sec`。
- 事件驱动模型：`网络启动($202,数据)` + `异步通知(网口,网窗,网络消息,协议)` + 窗口消息里处理 `接口请求/接口连接/接口读/接口关闭`（官方 `inc\网络通讯.sc` 全套实现可直接照搬）。

## 7. 进程 / 注册表 / 加密（文档 + 官方示例，部分未实测）

- 进程与模块遍历（官方 `code\进程.sec`）：
  ```
  进程类 进程(长度=296)模块类 模块(长度=1316)
  快照=进程快照(2,0);
  循环{ 发送消息(列表框1,列表添加,0,进程.名称); ... 遍历=下个进程(快照,进程); }(遍历=0)
  关闭对象(快照)
  ```
- 信息框/消息框（文档第十四节）：**不是内置符号**，要先 `导入 信息框 别名 MessageBoxA 支持库 "USER32.DLL",4;`（否则 `语法有误`）。按钮常量 `$000001` 确定取消、`$000004` 弹出是否、图标 `$000010` 错误、`$000020` 问号、`$000030` 惊叹、`$000040` 信息；返回值 `选了确定=1 选了取消=2 选了是=6 选了否=7`。**控制台程序里弹框必阻塞**（`开启线程`+`FindWindowA`+`WM_CLOSE` 也关不掉）→ 自动化测试请改用 `延时框`（超时自动关闭，实测返回 `32000`，见 `examples/14-sys-2.txt`）。
- 网络（官方 `code\连接测试.sec`）：`网络启动($202,数据); 网号=分配(2,1,6); IP.地址=转换地址(TIP); IP.端口=反转(端口); 连网(网号,IP,16); 关闭(网号)`；地址类 `地址类 IP(协议=2)`。
- 加密/哈希：`inc\哈希加密.sc`、`code\crc32.sec` 是现成参考（未亲自实测）。
- 注册表：官方 `code\注册表.sec` 演示 `注册表` 系列封装（未亲自实测）。

## 7. 实用注意

- 输出的换行：`写文字` 自带换行；要精确控制用 `写字符(13);写字符(10);`，字面量里的 `\r\n` 也有效。
- 中文输出在 GBK 代码页下正常；重定向抓取时按 GBK 解码。
- 控制台窗口标题可用来区分/定位进程窗口：`设置标题("xxx")`，随后可用 `scripts/shot.ps1 -Title xxx` 截图。
