# 03 · 基础语法与类型速查（文档表 + 实测校正）

## 2. 声明与书写

- 全局变量：写在第一个 `程序` 之前；局部变量：写在 `程序` 内（可加 `局部` 前缀）✅。
- 固定数组用**括号**：`整数 数一(10);` 索引 `数一(3)=66;` ✅；也接受 `整数 数组[5]` ✅。
- 动态数组：`整数 数二();` + `重置 数二(886679)`（文档；`重置` 用于数据表已 ✅）。
- 二维：`小数 数三(15,3); 数三(3)(0)=88.4567;`
- 文本：`文本 内容[64];`（长度必须是字面量；`文本 内容;` 是错的）。
- 语句分隔：换行或 `;`；空格不能代替分号（文档 1005–1007）。注释 `//` ✅。
- 中括号 `[表达式]`＝编译期求值；小括号表示运行时运算（文档 1374–1377）。

## 6. 文本与数组细节（文档第六节 1287–1400 行）

- `文本` = 一维字节数组；`数组` 元素长度按类型，文本/指针类默认 1 字节。
- `整数 内容(10); 内容(0)="中国"; 内容(1)="你好";` —— 用**整数数组**存字符串指针更灵活（文档 1308–1314）。
- 读写文本内部数据：`字节 数=内容(2);`（读第 3 字节）、`内容(2)=\A;`、`内容(2)%=\好;`（写 2 字节）、`内容(2)&=0#你好;`（写 4 字节）。
- 内置成员：`.指针` `.长度` `.维数` —— 📖 文档 1361–1370；⚠ 本版实测 `数组.指针` 报「未定义的名称」。
- 循环数组语法（批量读写内存/数组）：`循环数组(数>数组){数=值}`、`循环数组(数组&)-1` 等 12 种写法（文档 1371–1399，📖 未实测）。

## 7. 新手最常踩的 6 个坑（全部实测，详见 `02-language-core.md`）

1. 辅助 `程序` 写在入口前面 → 参数乱码/无输出（入口＝文件里第一个 `程序`）。
2. `文本 变量[32]="字面量";` → 死循环；用 `内存复制` / 拼表达式 / `整数 p="字面量";`。
3. `写格式("%s", 文本变量)` → 卡死；改用 `写文字(文本变量)`。
4. `判断` 链自己加 `结束` → 提前结束整个程序。
5. `写格式("%f", 浮点字面量)` → `0.000000`；用浮点变量拼文本。
6. 源码必须 **GBK + CRLF**，否则乱码或「内部错误」。
