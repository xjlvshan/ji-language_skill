## 1. 程序骨架与入口（实测·最关键）

```ji
程序类型=2
模块文件=CMD.inc
整数 全局数=100;          // 全局变量：写在第一个 程序 之前
程序 初始启动               // ★ 文件里第一个 程序/函数 就是程序入口
整数 a=7;                   // 函数内（含参数）都是局部变量
写格式("平方(a)=%d\r\n",平方(a));   // 注意：调用结果先赋值更稳
结束                        // 闭合 程序
程序 平方(数)               // 辅助函数必须放在入口之后
返回(数*数)
结束
```

证据：
- `m1.txt`（入口在前，辅助在后）→ `sq=25`；`m2.txt` → `sum=3`；`m3.txt` → `start [v=7]`。
- 反例 `s1.txt`/`u1.txt`（把带参辅助函数写在最前）→ 它**成了入口**，收到 CRT 启动参数，输出乱码或什么都不输出；`v6.txt`（`函数 取五` 写在最前）→ 进程退出码正好等于 `返回(5)` 的 5。
- `程序 名称(...)` 用 `程序`；用 `函数` 定义辅助函数会报 `初始启动 语法有误 + 内部错误`（实测 `kA.txt`、`gA5.txt`）。

## 2. 词法与书写规则

- 语句分隔：**换行或分号**都行；关键字后用空格分隔（`否则 处理窗口(...)`）。
- 注释：`//`（实测 `f3.txt`）。
- 中文关键字与中文运算符（如 `a 余 b`、`数 与 值`）均可直接书写。
- 转义（文档）：`\r` `\n` `\t`；字符字面量 `\A`；汉字可用 `\好` 这种两位写法参与 `%`/`&` 型内存写（文档第六节）。
- 中括号 `[表达式]` 表示**编译期**求值（数组长度、结构长度等必须是编译期常量）。
- 变量类型表（文档第二节，实测可用）：`布尔 字符 字节 短数/整形 正短/正数 整数 文本 小数/浮点 双精 大数 日期 变数`，以及 `结构 数据表 对象 变体类`。
- 任何变量作为**参数**传递都是 4 字节数值；只有需要浮点运算时才特别声明 `小数`。

## 3. 赋值与类型转换（实测）

- `=` 是「按左边类型转换后写入」：`整数 数=3+4*2;` → 11（实测 `b2.txt`）。
- 需要浮点运算时等号后加冒号：`数=:数一-数二`（文档）。
- **`%f` 打 0 的根因（bas 领域实测）**：`写格式` 就是 C 的 `printf`，`%f` 要栈上是 **8 字节 double**；而本版 `小数/浮点` 是 **4 字节 float** → 参数错位 → `0.000000`。`双精`（8 字节）与 `3.5#` 双精字面量用 `%f` 正常。四种可靠写法：
  1. 拼进文本再输出（最通用）：`b(0)=0; b=b+"小数="+单; 写文字(b);` → `小数=1.500000`（默认 6 位小数）
  2. `格式化(b,"%.4f",双); 写文字(b);`
  3. 先 `双精 提升=单;` 再 `写格式("%f",提升);`
  4. 本来就是双精：`写格式("%f",3.5#);` → `3.500000`
- 文本拼接会自动把数字转文本：
  ```ji
  浮点 f=2.5; 双精 d=1.25; 文本 buf[128]; buf="f="+f+" d="+d;
  写文字(buf);            // → f=2.500000 d=1.250000
  ```
  实测 `core-cheatsheet.txt`：浮点默认 **6 位小数**；整数默认十进制；`减` 运算是十六进制文本（文档）。
- 赋值运算符可省略等号：`a+2; a/10;`（文档）。
- `?`＝上次赋值结果，`??`＝纳秒计数器低 32 位（文档，未实测）。

## 4. 运算符（文档第四节 + 实测修正）

| 中文 | 符号 | 备注 |
|---|---|---|
| 加 减 乘 除 | `+ - * /` | 实测 `a+b=9 a-b=5 a*b=14 a/b=3`（整数除法取整） |
| 余（取模） | `%` | **必须写中文**：`整数 m=a 余 b;` → `mod=1`（实测 `i1.txt`）。写 `a%b` 会触发编译器内部错误（`h2.txt`），`a%=2` 会卡死（`i2.txt`） |
| 或 与 异 | `| & ^` | `&` 还兼任：取地址、取 4 字节内存值 |
| 非 反 | `! ~` | |
| 右移 / 左移 | `>>` / `<<` | `a>>1` 实测可用（`x1` 系列） |
| 比较 | `=` `!=` `<>` `>` `>=` `<` `<=` | `如果(数=值)` 里 `=` 是相等判断 |
| `%` 后缀 | — | 在变量/数组后表示取 **2 字节**内存值；`&` 取 4 字节；无后缀取 1 字节；`!` 取 4 字节浮点 |
| 浮点函数 | `(表达式)绝对值 / 余弦 / 正弦 / 平方根 / 正切 / 反正切` | 文档 |

运算符实测禁区（bas 领域 8 个示例 + 主 agent 复验）：

- **变量做符号位运算会编译失败**：`写格式("%d",数|值)` → `语法有误`。变量必须写中文 `数 或 值` / `与` / `异` / `反 数` / `非 数` / `数 右移 值`；符号形式（`1|2=3`、`8>>1=4`）只对**字面量**有效。
- **比较不能当表达式**：`整数 甲=数>值;`、`写格式("%d",数>值)` 都是 `语法有误`；比较只能出现在 `如果/判断/循环/如果是` 的条件里，取值用 `如果是`。
- `&&` `||` `而且` `或者`、中文比较词（`数 大于 值`）**全部不可用**（`未定义的名称:大于` 等）→ 多条件用嵌套 `如果`。
- `如果是(条件,a,b)` 里 `=` 是**赋值**不是比较：条件必须写 `>`/`<`/`<>`（实测 `如果是(数>值,100,200)=100`）。
- `检索` **必须三参**：`检索(数组,值,长度)`；两参报 `未知的数组类型`。
- 中括号 `[表达式]` 是**编译期**求值，且**内部从左到右、无优先级**：`[6+[35-12]*150-[60/12]]=4345`（即 `((6+[23])*150)-[5]`，实测 adv-5）。
- `常量 名称=值;` 可用且能当结构体数组长度（adv-5：`表2(3).甲=7 行数=4`）。

## 5. 控制流（全部实测通过，见 `examples/02-flows-cheatsheet.txt`）

```ji
如果(i<5){写文字("lt5");}
否则{写文字("ge5");}

写格式("如果是=%d\r\n",如果是(a>2,111,222));   // → 如果是=111

循环于(i=0;i<3;i++){写格式("%d ",i);}           // C 风格 for，必须写 循环于（写 循环(...) 报「语法有误」，实测 b4）
循环(2){写字符(42);}                             // 固定次数
循环在(i<3){写格式("%d ",i);i++;}                // while
循环{写格式("%d ",i);i--;如果(i=0){跳出;}}        // 无限循环 + 跳出
```

判断（switch）：

```ji
判断(i)
为 0,1{写文字("zero-one");}      // 多值：逗号
为 2{写文字("two");}
否则{写文字("other");}
                                  // ★ 不要写 结束：判断链由「外层的 结束」收尾
```

证据：
- `jud2.txt`（判断链后还有语句、最后只有一个 `结束`）→ `BUILD_OK`，输出 `three i=3`。
- `jud1.txt`（判断链自己加了 `结束`，后面还有代码）→ `未定义的名称:i [第7行]`：那个 `结束` **提前结束了整个程序**，后面的局部变量就"不存在"了。
- 因此把 `判断` 放在程序最后一段最安全（`02-flows-cheatsheet.txt` 已验证）。

其他（文档）：`跳到 标记`、`跳转>标记`、`标记 位置`；`循环数组(...)` 批量读写内存/数组。

## 6. 函数（实测）

```ji
程序 平方(数)          // 参数按值传递（4 字节），可带默认值：程序 平方(数=2)
返回(数*数)            // 返回整数；浮点结果写 返回(:表达式)
结束
```

- 调用：`整数 r=平方(a);` 或直接 `显示(7);`（实测 `m1/m2/m3`、`h3.txt`、`h6.txt`）。
- 无返回值的过程直接 `名称;` 调用（实测 `w4.txt`）。
- **建议**：把带返回值的调用结果先赋给变量，再传给 `写格式(...)`；把裸字面量直接作为实参塞进 `写格式` 会偶发卡死（实测 `gA5` 卡死 vs `h6` 正常）。
- `局部 整数 x=9;` 显式声明局部变量（实测 `f3.txt`）。

## 7. 数组与文本缓冲区（实测）

```ji
整数 数组(5);        // 固定数组（括号）；也支持 [5] 写法
数组(0)=10; 数组(4)=50;
写格式("数组=%d,%d\r\n",数组(0),数组(4));    // → 数组=10,50

整数 动态();          // 动态数组
重置 动态(100);       // 重新分配并清零（文档）
保留 动态(200);       // 保留原数据扩容（文档）

文本 名字[32];        // 文本＝定长字节缓冲区（长度必须是编译期常量）
内存复制(名字,"极语言",7);   // 7 = 3 个汉字*2 + 结尾 '\0'
写文字(名字);                 // → 极语言

文本 内容[64];
内存复制(内容,"0123456789ABCDEF",17);
写格式("内容(2)=%d\r\n",内容(2));   // → 内容(2)=50（字符 '2' 的 ASCII）
```

要点与坑：

- ★ `文本` 字面量赋值分两种情况（主 agent + bas 领域双向复验）：
  - **全局声明行给初值是可以的**：`文本 全局文本[32]="文本";` → 正常输出。
  - **运行期赋值**（`s="字面量";`）和**例程内声明带初值**（`程序` 里 `文本 s[32]="abc";`）会**死循环卡死**（连卡 4 次，控制台停在赋值前）。
  - ★ **加 `定义 位数=64;` 后局部带初值也正常**（实测 w64a → `abc`）；结构体含文本成员、子类无参方法同理（w64b/w64c）。这是本版文本类卡死的通用解药。
  - 安全写法：`内存复制(s,"文字",字节数)`、`s=s+"文字"`、`整数 p="文字";`（字面量本身是指针）。
  - 拼接前先 `s(0)=0;` 清缓冲区，否则会粘上别的缓冲区残渣；`s=""+"abc"` 会得到 `0abc`（空串被当整数 0）。
- `写格式("%s", 文本变量)` 卡死（实测 z4/y5）；文本变量请用 `写文字(...)` 输出。
- 字面量可直接用于 `写格式` 的 `%s`：`写格式("字面量=%s\r\n","hello")` → `字面量=hello`（实测 core-cheatsheet）。
- 整数数组越界不报错；数组/文本的 `.长度`、`.指针` 成员在本版**不可用**（报 `未定义的名称:数组.指针`，实测 `f2.txt`）。
- 数组与文本都可用指针语法读写（见下）。

## 8. 指针与内存（实测 + 文档）

```ji
文本 内容[64];
内存复制(内容,"0123456789ABCDEF",17);
字节 b=内容(2);        // 读 1 字节（偏移 2）
整数 数值=内容;         // 取缓冲区地址（也可 整数 p="字面量";）
整数 m=申请内存(128);   // 申请内存
m(13)=128;             // 向第 14 字节写入
a=m(10);               // 从第 11 字节读 1 字节
释放内存(m);            // （文档；对应函数名见 05 控制台/系统笔记）
```

按长度读写（文档第七节，符号在变量或 `变量(偏移)` 之后）：

| 写法 | 含义 |
|---|---|
| `变量(偏离)` | 1 字节 |
| `变量(偏离)%` | 2 字节 |
| `变量(偏离)&` | 4 字节 |
| `变量(偏离)!` | 4 字节浮点 |
| `.偏移` / `.%偏移` / `.&偏移` / `.!偏移` | 相对当前列举基址 |
| `#偏移` / `#%偏移` | 旧式虚指针偏移 |

`&` 的多重含义（文档）：表达式中=与运算；变量前=取地址；变量后=取 4 字节内存值。

## 9. 结构体 / 数据表 / 子类（文档 + 分领域笔记）

```ji
结构 窗口类{整数 句柄,左边; 文本 标题[64],内容[256]}
窗口类 窗一;
窗一.标题="你好";           // 注意文本字面量赋值的坑，见 §7

数据表 人物表{整数 生命,内功; 字节 等级,职业;}
重置 人物表(100);
人物表(2).等级=10;

子类 角色类{整数 攻击,防御; 程序 计算(角色类 人物) ... 结束}
整数 人物=新建 角色类;
人物.攻击=30;
人物.计算(@)
```

- 结构与数据表的字段用 `.` 访问；数组式索引 `名称(序号).字段`。
- 子类是"整数指针实体"，用 `新建` 创建、`销毁` 释放；子类内部用 `@` 代表自身。
- 详细实测（含可运行示例与失败记录）见 `references/04-advanced.md`。
